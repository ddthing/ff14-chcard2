# XXD UI Kit icon attribution

This project vendors the icon node data from [nevertoday/xxd-ui-kit](https://github.com/nevertoday/xxd-ui-kit), package `@xxd/icons`, at commit `a7a811eecff45538bbc950d1e57ce4cd8efeb674`.

- Source file: [`packages/xxd-icons/src/nodes.js`](https://github.com/nevertoday/xxd-ui-kit/blob/a7a811eecff45538bbc950d1e57ce4cd8efeb674/packages/xxd-icons/src/nodes.js) (blob `5cbd041fb42189fa55ddce59a7989d3d2cfdb432`)
- Upstream README describes the set as 24-unit icons with a 1.5-unit stroke. The package metadata identifies the package license as MIT.
- The vendored JavaScript bytes match the upstream Git blob exactly; `git hash-object` returns `5cbd041fb42189fa55ddce59a7989d3d2cfdb432`. `nodes.d.ts` adds only local TypeScript declarations for that source.
- The complete upstream MIT license and copyright notice are preserved in [LICENSE.txt](./LICENSE.txt).

The shared application icon component applies the source paths with the upstream 24×24 viewBox and 1.5-unit, round-cap, miter-join stroke. XIVAPI job icons remain separate.
