# 홈 최우선 UX 수정

2026-10-11 비판적 디자인 검토의 수정 목록을 사용자가 “응 진행”으로 승인했다. B · Card Stage와 설치된 Stone 원본 토큰을 유지하면서 작업 흐름과 정보 위계를 수정했다.

## 반영한 수정

- 고정 548px 무대를 화면 높이에 맞추도록 변경했다. 실제 마케팅 헤더 높이 72px/64px와 초안 행 유무를 계산에 반영하고, 카드 크기·후면 겹침을 함께 조정한다. 선택 중에는 세 노드의 key와 기본 폭이 유지된다.
- 초안의 작업 재개를 제목 다음, 무대 앞에 배치했다. 모바일 재개는 전체 폭의 44px outline 행동이다. 기존 live 저장 상태를 KO/EN/JA의 자동저장 문구로 명확히 했다.
- 보관 폼에 실제 저장할 카드 이름과 저장된 template 이름을 표시하고 홈 전용 제출 문구를 “프로젝트로 보관”으로 바꿨다. 예시 무대의 선택은 보관 대상 데이터를 바꾸지 않는다. 초안이 없는 경우에도 실제 starter의 Cinematic 스타일을 정확히 표시한다.
- 선택한 예시 이름을 카드 아래 도크 가까운 figcaption으로 옮겼다. 초안이 있으면 “내 카드로 비교”가 기존 `compare=personal` 모드로 연결된다. 이 모드는 같은 사진·데이터로 세 스타일을 비교한다. 기본 예시는 기존 작품 구도를 유지한다.
- 홈 보관 표면의 제목은 18px, 입력 값은 14px로 하고 레이블을 입력 위에 배치했다. 에디터 dialog의 문구·기본 레이아웃·확인 흐름은 바꾸지 않았다.

## 검증

- 전체 테스트 281개: 252개 통과, 기존 archive 29개 건너뜀, 실패 0. 타입 검사·전체 ESLint·프로덕션 빌드 통과.
- Windows sandbox의 경로 접근 제한으로 최초 빌드가 실패했으나, 경로 접근이 가능한 실행 환경에서 동일 명령을 다시 실행해 성공했다. 검증 서버도 localhost 소켓 접근이 가능한 환경에서 실행했다.
- 초안 있음/없음 × KO/EN/JA × light/dark × 7개 viewport × 3개 스타일 = 252개 조합 통과. Viewport는 1280×720, 1366×768, 1266×712, 1440×900, 768×900, 390×844, 320×844다.
- 자동 스크롤로 결과를 오인하지 않도록 DOM 좌표에 scrollY를 더해 초기 페이지 위치 기준으로 검사했다. 실제 폭·높이, 제작/스타일 버튼과 재개 가시성, 44px 높이, 중앙 카드 포함, 넘침, 단일 선택·후면 접근성 숨김과 실제 링크 template을 확인했다. 720px 화면에서 제작 버튼의 최대 하단 위치는 699.40625px였다.
- 긴 한글·라틴·일본어 혼합 이름으로 3개 언어 × 1280×720/390×844/320×844의 추가 9개 조합을 확인했다. 버튼 밀림과 가로 넘침이 없었다.
- Enter로 스타일을 선택하고 포커스 유지·링크를 확인했다. 첫 사용자 starter와 기존 초안을 실제 보관해 목록의 이름·스타일이 표시된 대상과 일치함을 확인했다. 개인 비교의 내 카드 상태와 세 사진 src의 일치를 확인했다.
- 에디터 프로젝트 dialog의 기존 “현재 카드 저장” 문구와 stage 대상 문구 미노출, Escape 닫기를 확인했다. 독립 소스 검토에서도 renderer/store/appearance 경계의 회귀를 발견하지 않았다.
