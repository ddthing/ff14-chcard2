# 네 모서리 장식과 모험가 기록 사진 확장

2026-10-13 사용자 요청에 따라 시네마틱·모험가 기록의 네 모서리를 카드 크기에 맞추고, 모험가 기록 사진을 카드 끝까지 확장했다. 앱 테마 계약은 변경하지 않았다.

## 적용

- 공유 `PrintFrame`의 카드 전용 기하는 실제 카드의 짧은 변을 기준으로 한다. 모서리 크기는 7.2%, 가장자리 여백은 1.67%다. 네 위치에서 같은 크기와 여백을 사용한다.
- 바깥·안쪽 테두리를 SVG 모서리 경로에 연결하고, 중첩된 사각 프레임을 제거했다. 기존 잎 문양에는 작은 잎맥 선을 보강했다.
- 모험가 기록의 세로·정사각 비율은 상단 사진이 위·좌·우 가장자리를 채운다. 16:9는 왼쪽 사진이 카드 높이를 채우고 오른쪽 기록 면과 이어진다.
- 16:9의 경계 장식은 사진·기록 면의 경계 중앙으로 옮겨 세로로 배치했다. 이전 상단 위치에서 잘리던 문제가 해소됐다.
- 사진 crop·보정, 단일 렌더러·내보내기, 저장 스키마와 원본 직업 아이콘 경로는 유지했다.

## 검증

- 타입 검사, ESLint, 프로덕션 빌드, `git diff --check` 통과.
- 전체 테스트 314개 통과, 실패 0, 역사적 아카이브 29개 skip.
- 실제 편집 화면: 모험가 기록은 390px에서 다섯 비율, 시네마틱은 1440px에서 다섯 비율의 모서리 크기·네 방향 여백·가시성·페이지 overflow를 실측했다. 모험가 기록은 사진·종이 면의 연결 위치도 확인했다.
- 추가로 1440px 모험가 기록 16:9의 경계 장식이 카드 안에 포함됨을 실측하고, 320px 일본어·다크 화면에서 가로 overflow 없음을 확인했다. 모든 비율·언어·테마의 전체 교차 조합을 실행한 것은 아니다.
- 실제 PNG 4:5 출력은 2,160×2,700, WebP 16:9 출력은 3,840×2,160이다. 두 파일의 MIME과 이미지 디코딩을 확인하고 PNG 결과 미리보기를 검수했다.
- 독립 검토에서 발견한 안쪽 테두리의 5/64 간격과 가로형 경계 장식 잘림을 수정하고 재검토했다.

실측 원시는 git 제외 경로 `tmp/corner-geometry-proof.json`, 최종 테스트 로그는 `tmp/corner-tests-final.txt`에 보관했다. 브라우저 검수는 별도 origin의 개발 서버에서 수행했다. 프로덕션 정적 서버의 전체 네트워크 바인딩은 자동 승인 검토에서 외부 파일 노출 가능성으로 거부되어 실행하지 않았다. 프로덕션 빌드는 별도로 통과했다.
