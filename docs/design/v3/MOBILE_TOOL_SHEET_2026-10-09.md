# 모바일 도구 시트 개선 · 2026-10-09

사용자 요청: 모바일 탭을 누르면 옵션이 아래로 붙는 동작을 개선.

## 바뀐 사용 방식

- 모바일 첫 화면은 옵션을 닫고 카드를 크게 표시한다.
- 사진·정보·디자인은 화면 아래 도구 독에서 선택한다. 옵션은 독 위의 독립된 시트로 열린다.
- 같은 도구를 다시 누르면 닫히며 다른 도구는 같은 시트에서 전환된다. 페이지가 아래로 길어지지 않는다.
- 닫기, Escape, 손잡이 클릭·아래로 쓸어 닫기를 제공한다. 닫은 뒤 도구 버튼으로 포커스를 복구한다.
- 도구 독은 toolbar의 disclosure button, 시트는 nonmodal region이다. 데스크톱 tablist/tabpanel 의미는 유지한다.
- 입력 공간이 줄어들면 독·불필요한 도구·미리보기를 접어 입력칸과 44px 닫기를 확보한다. 실제 OS 키보드를 검사한 결과로 표현하지 않는다.
- 기본 예시에는 모바일 미리보기 안에서도 예시 배지를 표시한다. 고유명사 입력은 spellcheck를 끄고 모바일 입력은 16px로 표시한다.

## 비판적 검수에서 보완한 점

- 방향키로 도구에 포커스만 옮긴 뒤 시트를 닫아도, 복구되는 버튼이 toolbar의 tab stop이 되도록 맞춤.
- 작은 입력 모드에 남아 있던 88px 높이 차감 규칙을 제거하고, 실제 위·아래 여백만 제외한 공간을 사용.
- 절대 위치 시트에 남아 있던 width:100%를 width:auto로 바꿔 양쪽 10px 여백이 실제로 반영되게 수정.
- 새로운 UI 높이 토큰을 카드 렌더 경계에서 초기화해 카드로 유입되지 않게 함.

## 실제 확인

- KO/EN/JA × 모바일 320/390/768px × 기본 닫힘·세 도구 열림과 데스크톱 1440px: 총 39개 구성에서 시트 경계 잘림·가로 넘침·기본 자동 열림 없음.
- 390×844에서 도구 독 y776–836, 열린 정보 시트 y363–768, 양쪽 경계 x10–380. 문서 높이 844px 유지.
- 기본 카드 326×407, 정보 시트를 열면 카드가 상단 미리보기 영역에 유지됨. 메인 CardPreview는 같은 인스턴스다.
- 같은 도구 재탭 닫힘, 방향키 포커스 이동 중 시트 유지, Escape 후 해당 도구의 tabindex=0으로 포커스 복귀 확인.
- 손잡이에서 아래로 75px 쓸어 닫힘 확인.
- 390×430에서 입력에 포커스 후 390×260으로 줄여 검수: 문서 높이 260px, 시트 높이 137px, 이름 입력 y168–216으로 전체 노출. 닫기 44×44 유지. 실제 휴대폰 키보드·홈 인디케이터 검수는 별도 대상.
- 소스 검사 239 통과, 과거 아카이브 그룹 29개 명시적 skip. 최종 추가 집중 검사 8 통과. 린트 및 프로덕션 빌드 통과. 전체 카드 출력 조합은 이번에 새로 생성하지 않음.
