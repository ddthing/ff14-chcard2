# Card Stage · 선택 경험과 카드 조판 개선

2026-10-13 사용자의 UI/UX·카드 디자인 업그레이드 요청에 따른 변경이다. 루트 `DESIGN.md`의 Stone 테마와 기존 Card Stage 구도를 유지한다.

## 방향과 변경

FF14 플레이어의 실제 카드가 중심이 되는 아틀리에다. 홈의 겹친 작품을 직접 선택할 수 있게 하고, 스타일 비교의 선택 상태와 이름을 읽기 쉽게 만든다. 기존 등록 서체·팔레트·모서리·라우트를 사용한다. 디자인 검토 설정은 변화 7, 모션 3, 밀도 5이며, 전환은 선택에 대한 짧은 피드백에 한정한다.

- 홈: 세 실제 마스터를 native button으로 선택한다. 도크와 같은 선택값·다음 경로를 공유한다. 중립 그림자로 작품의 겹침을 드러내고 도크의 스타일 선택을 하나의 그룹으로 묶었다. 동작 줄이기에서도 세 작품과 선택 기능이 모두 남는다.
- 스타일: 선택 작품의 경계·체크·깊이와 18px 이름으로 위계를 강화했다. 모바일에 세 스타일을 바로 선택하는 버튼을 추가하고 기존 스와이프와 연결했다. 내 카드가 없을 때는 해당 비교 버튼 옆에 이유를 표시한다.
- 카드: 에디토리얼의 직업·레벨, 월드·데이터 센터, 종족·부족, 소속·서비스를 묶고 그룹 경계에 구분선을 둔다. 후속 사용자 피드백에 따라 선은 글자 길이와 무관하게 정보 행 전체 폭으로 통일하고 마지막 행 아래에도 같은 길이의 마감선을 표시한다. 값 영역을 넓히되 기존 레이블 크기와 대비는 유지한다. 시네마틱의 영문 이름 최대 크기만 20% 줄였고, 측정 기준과 한글·일본어 상한은 바꾸지 않았다.

## 같은 요청에서 추가된 편집기 요구사항

사용자는 이어서 번호 안내는 유용하지만 글꼴 선택·편집 영역이 크고 모든 작은 항목을 각각 조절하는 방식이 피곤하다고 설명했다. 이름·한 줄 소개·카드 문구만 개별 서체 대상으로 남기고, 작은 정보와 레이블은 하나의 서체 세트로 조절하는 방향이다. 카드 위에서는 실제 글자 범위를 표시하고, 터치 영역과 눈에 보이는 외곽선을 분리한다.

정보 그룹의 변경은 기존 `textTypography` 맵을 한 번에 갱신하는 방식으로 구현한다. 사용자가 설정을 바꾸기 전에는 기존 항목별 설정을 유지하며, 그룹의 한 번 변경은 한 번의 실행 취소로 복원한다. 데이터 스키마를 새로 만들거나 기존 초안을 일괄 변환하지 않는다.

글꼴은 한 개의 선택 상자와 크기 슬라이더로 표시하며 굵기·자간은 접힌 세부 설정에 둔다. 정보 그룹은 이름·소개·장식 문구를 제외한 현재 마스터의 정보값과 레이블을 대상으로 한다. 글꼴 변경은 다른 속성을 보존하고, 크기는 각 역할의 기존 비율을 유지하는 상대 배율이다. 그룹 초기화는 이 항목들의 개별 서체 설정만 지워 기존 역할 서체를 다시 상속한다.

카드 위 윤곽선은 텍스트 Range의 행별 범위를 따른다. 투명한 조작 영역과 시각적 윤곽선을 분리하며, 이름·소개·문구만 번호를 표시한다. 정보에는 이웃 글자를 가리지 않는 위치가 있을 때 그룹 표시 하나를 둔다. 번호·그룹 표시는 카드 출력 경로 밖에 있다.

긴 소개가 없어지는 조건도 수정했다. 시네마틱 9:16·16:9의 숨김, 모험가 기록의 긴 한글·일본어 이름 조건부 생략, 에디토리얼 사진 면의 소개 줄 잘림을 제거하고 기존 측정 기반 맞춤을 사용한다. 비어 있는 문구를 사용자가 의도적으로 지웠을 때의 생략은 유지한다.

모험가 기록에 긴 이름·소개와 긴 플레이스타일 다섯 개가 함께 있을 때는 1:1·4:5·3:4의 정보 행을 내용 높이에 맞춰 배치한다. 4:5와 3:4에서는 이 경우에만 사진/종이 경계를 조금 위로 옮겨 공간을 확보한다. 글자나 필드를 생략하거나 기존 정보 서체를 일괄 축소하지 않는다.

플레이스타일의 한국어 선택지는 사용자가 직접 제시한 PvP, PvE, 터주, 하우징, 마작, 지도&보물고, 라이트, 즐겜, 하드컨텐츠, 초보, 새싹, 업적, 제작, RP, 스샷, 절, 복귀, 골드소서, 디스코드, 인게임 위주, 트위터 교류를 포함한다. 이 목록을 실제 사용 빈도 조사 결과로 주장하지 않는다. 기존 ID와 이전 한국어·영어·일본어 표시 이름의 aliases를 보존한다.
