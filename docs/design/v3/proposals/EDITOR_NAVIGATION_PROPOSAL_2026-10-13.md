# 편집기 탐색·문구 편집 수정안

상태: 2026-10-13 사용자 승인 후 적용. [구현·검증 기록](../EDITOR_NAVIGATION_REFINEMENT_2026-10-13.md)을 함께 확인한다.
근거: 2026-10-13 사용자가 첨부한 데스크톱·모바일 화면과 표시한 위치.

## 수정 방향

데스크톱은 패널에 붙어 있는 조작부와 번호 목록으로 편집 대상을 명확히 한다. 모바일은 카드가 중심인 화면과 실제 입력 화면을 구분하고, 손가락이 닿는 아래쪽에서 편집을 시작한다. 기존 Stone 표면·반경, 파란 선택 토큰, 등록 서체와 XXD 기능 아이콘을 유지한다. 문구 목록에는 장식 아이콘을 쓰지 않는다.

## 1. 접기 버튼: 항목 패널 제목 오른쪽

- 헤더의 앱 메뉴 옆에 있는 접기 버튼을 제거한다. 펼친 데스크톱에서는 `편집 항목` 제목 오른쪽에 접기 버튼 하나를 둔다. 44px 조작 영역과 `편집 항목 접기` 접근성 이름을 제공한다.
- 접으면 도구 레일과 항목 목록을 모두 제거하고 캔버스가 해당 폭을 사용한다. 빈 왼쪽 열이나 남아 있는 레일을 예약하지 않는다.
- 접힌 상태에는 캔버스 왼쪽 위의 카드 바깥 여백에 `항목 열기` 버튼 하나를 표시한다. 펼침 상태의 접기 버튼과 동시에 표시하지 않는다. 맞춤 계산에서 이 조작 영역을 확보해 카드와 겹치지 않게 한다.
- 901–1180px에서는 `항목 열기`가 서랍을 열고 서랍 제목 오른쪽에서 닫는다. 모바일에는 이 데스크톱 접기 조작을 표시하지 않는다. 문구 작업 안에서 항목을 고른다.

## 2. 문구 목록: 번호 → 이름 → 현재 문장

```text
편집 항목                              [접기]

이름 · 소개
1. 이름
   Coner
2. 한 줄 소개
   작은 걸음이 모여 긴 여정으로 이어집니다.

카드 문구
3. 제호
   모험가 카드
4. 이야기
   이야기는 계속됩니다.
5. 빛의 전사
   빛의 전사

정보 세트
   직업 · 레벨 · 서버 · 자유부대 …
```

- 문구 앞의 사람·반짝임 아이콘과 오른쪽의 작은 번호를 삭제한다. 번호는 제목 바로 앞, 실제 문장은 그 아래에 둔다.
- 위 번호는 첨부한 에디토리얼 카드 기준이다. 다른 템플릿에서는 실제 편집 가능한 문구만 나열하고 카드와 목록에 같은 번호를 사용한다.
- 행 전체를 선택하면 우측 편집기에 해당 텍스트 입력칸이 바로 보인다. 입력칸 아래에 실제 문장으로 미리 보는 글꼴 선택기와 크기를 둔다. 자간·굵기 등은 `세부 설정`으로 접는다.
- 카드의 문구를 직접 눌러도 같은 입력칸으로 연결한다. 선택만으로 모바일 키보드를 강제로 열지 않고 입력칸을 눌렀을 때 연다.
- 작은 정보는 `정보 세트` 하나로 선택하고 서체·초기화·실행 취소를 함께 적용한다. 개별 정보값 수정은 그 안의 프로필 정보에서 제공한다.

## 3. 사진 조절: 이름·숫자·슬라이더를 가까이

```text
사진 조절                       조절 초기화

가로 위치                              [44]
────────────●─────────────────────────────

세로 위치                               [0]
●─────────────────────────────────────────

사진 확대                             [90%]
────●─────────────────────────────────────
```

- 이름과 숫자 입력을 같은 행에 두고, 슬라이더를 바로 아래에 둔다. 세 조절 묶음 사이의 큰 빈 공간을 줄인다.
- 값 입력과 슬라이더의 터치 영역은 44px 이상 유지한다. 슬라이더는 시각적인 선이 얇아도 조작 영역은 충분히 확보한다.
- 사진 확대 `0.9`는 `90%`로 표시한다. 카드 자체의 확대율은 더보기의 `화면 확대`로 분리해 두 확대 기능의 뜻을 명확히 한다.

## 4. 모바일: 아래쪽의 단일 작업 바

### 카드 보기

```text
┌─────────────────────────────────┐
│ 메뉴    XIV / ATELIER   언어  저장 │
├─────────────────────────────────┤
│                                 │
│         실제 카드 미리보기         │
│                                 │
│                                 │
│   사진     문구     디자인   더보기 │
└────────── 하단 안전 영역 ──────────┘
```

- 헤더 바로 아래의 사진·내용·디자인 줄을 없앤다. 헤더는 56px 한 줄이며 언어와 이미지 저장을 유지한다.
- 작업 바는 하단 안전 영역 위에 하나만 둔다. 높이 52px, 좌우 12px 여백, 기존 반경과 얇은 경계로 처리한다. 네 버튼은 같은 너비와 44px 이상 조작 영역을 갖는다. 텍스트 이름을 직접 보여준다.
- `사진 / 문구 / 디자인`은 편집 패널을 연다. `더보기`에 실행 취소·다시 실행·화면 확대·캔버스 맞춤·미리보기 등을 모은다. 카드 위의 더보기 버튼은 제거한다.
- 카드 맞춤은 실제 헤더·작업 바·safe-area를 제외한 공간으로 계산한다. 초기 화면에서 카드 전체가 보이고 하단 작업 바가 카드나 비율 표시를 가리지 않아야 한다. 비율·확대 메타데이터는 더보기에서 제공한다.

### 편집 중

- 보통 높이의 세로 화면에서는 작업 바 위에 속성 시트를 연다. 시트는 가용 작업 높이의 절반 정도에서 시작하고 내부만 스크롤한다. 상단에는 현재 대상과 닫기를 고정한다.
- 문구를 선택하면 `1. 이름` 같은 제목, 문장 입력, 실제 모양이 보이는 글꼴 선택 순서로 시작한다. 제목 옆 `항목 선택`에서 번호 목록과 정보 세트를 고른다. 별도의 레이어 서랍을 추가하지 않는다.
- 작업 바의 다른 도구를 누르면 같은 시트의 내용만 전환한다. 현재 도구를 다시 누르거나 시트의 닫기를 누르면 카드 보기로 돌아간다. 현재 도구와 패널 열림 상태는 구분해 표현한다.
- 키보드가 열리거나 미리보기와 입력을 함께 놓을 높이가 부족하면 작업 바를 숨기고 시트를 입력 중심 화면으로 확장한다. 상단의 `카드 보기`로 돌아갈 수 있게 하고 입력칸을 visualViewport 안에 유지한다.
- 가로·짧은 화면에서는 카드와 작은 시트를 억지로 동시에 배치하지 않는다. 입력 화면과 카드 보기를 전환하며, 키보드가 닫히면 직전 선택과 화면을 복구한다.

## 5. 선택·모션과 완료 기준

- 목록·작업 바·속성의 현재 대상에는 같은 파란 표면·선택 선을 사용한다. hover, 현재 선택, 키보드 focus를 각각 구분한다. 문구 번호는 실제 텍스트 조각과 연결하고 문구 밖의 넓은 영역을 덮지 않는다.
- 기존 공통 모션 토큰을 사용한다. 선택과 슬라이더 값은 즉시 반영하고, 시트 등장에만 짧은 전환을 사용한다. 패널 접기 후 카드는 최종 가용 공간에 맞추고 카드 크기를 탄성 애니메이션으로 흔들지 않는다. reduced-motion에서 전환을 제거한다.
- 320px·390px·480px, 900/901px와 1180/1181px 경계, 1440px, 844×390 가로, 320×390 짧은 화면에서 확인한다. KO/EN/JA, 밝게/어둡게, 200% 확대, 키보드·IME, 안전 영역도 포함한다.
- 접기 버튼이 동시에 두 개 나타나지 않고, 접힌 뒤 남은 열·여백이 없어야 한다. 재열기 버튼이 카드와 겹치지 않아야 한다.
- 문구 목록 → 입력, 카드 문구 → 입력이 같은 대상에 연결되어야 한다. 긴 문장과 폰트 변경 후에도 카드 정보의 구분선이 전체 정보 열 너비를 유지하고 장식이나 글자가 사라지지 않아야 한다.
- 모바일 기본·시트 열림·키보드 열림을 같은 데이터로 나란히 캡처해 배치와 밀도를 검토한다. 기능 테스트 통과만으로 디자인 검토를 대체하지 않는다.

이 수정안을 반영하면서 DESIGN.md §5.1의 헤더 접기 위치와 모바일 작업 바 규칙을 갱신했다. 이 문서는 승인된 수정 방향이며 실제 검증 범위는 별도의 구현·검증 기록을 따른다.
