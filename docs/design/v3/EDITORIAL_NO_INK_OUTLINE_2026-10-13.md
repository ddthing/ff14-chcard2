# 에디토리얼 사진의 검은 가장자리 제거

2026-10-13 사용자 요청에 따라 사진 마스크의 검은 테두리를 제거했다. 이전 문서의 의도된 잉크 가장자리 설명은 당시 구현의 기록이며, 현재는 이 요청이 우선한다.

사진 뒤에 같은 붓결 clip을 적용하고 1.018배로 확대한 `.brushUnderlay`를 마크업과 CSS에서 제거했다. 사진을 자르는 원본 SVG 경로, 비율별 사진 영역, crop·보정·인쇄 효과, 배경 사진과 종이 재료는 유지한다. 사진의 `data-card-local-clip`도 유지하여 내보내기 복사본이 같은 SVG clip을 사용한다.

## 검증

- 기존 검은 밑그림 요구 테스트를 현재 계약에 맞춰 수정하고, 원본 붓 경로 hash·clip·내보내기 식별자 보존 검사를 유지했다.
- 전체 테스트 317개 통과, 실패 0, 역사적 아카이브 29개 skip. 타입 검사·ESLint·프로덕션 빌드·`git diff --check` 통과.
- 같은 대표 사진의 전후 화면을 비교했다. 별도 밝은 테스트 이미지로 검은 밑그림 없이 사진색이 붓결 가장자리까지 이어짐을 확인했다.
- 실제 편집 화면에서 다섯 비율 모두 잉크 밑그림 부재와 원본 사진 clip을 확인했다. 9:16의 stacked 구도와 나머지 side-panel 구도를 유지한다. 390px 화면에서 페이지 overflow가 없었다.
- 밝은 테스트 이미지의 실제 PNG 2× 출력은 2,160×2,700이다. 디코딩한 출력의 왼쪽 절반에서 RGB 각각 70 미만·alpha 200 초과인 어두운 픽셀은 0개였다. 이 검사는 인위적인 검은 밑그림 제거를 확인하며, 사용자가 올린 사진 자체의 어두운 픽셀을 없애는 처리는 아니다.

검수는 별도 origin·격리된 브라우저 저장소에서 진행했다. 사용자 사진과 초안·저장 형식을 수정하지 않았다.
