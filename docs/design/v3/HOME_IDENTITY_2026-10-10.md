# XIV / ATELIER 홈 정체성 · 2026-10-10

사용자 피드백: 위계 정리 후 화면이 너무 특색 없게 보인다.

## 디자인 판단

현재 홈은 카드 내부에만 개성이 남고, 앱 바깥은 작은 제목·회색 선·썸네일 선택기로 이어져 일반 관리 화면처럼 보였다. 새 문구나 색상 테마를 추가하기보다 기존 XIV / ATELIER 타이포그래피와 실제 카드 작품의 조판을 강화한다.

홈 소개와 작품 진열 부분에 `design-taste-frontend`의 리디자인 검토 방식을 적용했다. 밀도 있는 입력·목록 영역에는 마케팅 장식을 확장하지 않는다. DESIGN_VARIANCE 8, MOTION_INTENSITY 3, VISUAL_DENSITY 8로 판단한다. Stone 프리셋·기존 등록 서체·앱 라우트·제목 의미·짧은 문구는 유지한다. 새 라이브러리나 이미지를 설치하지 않는다.

## 적용

- 큰 XIV 타이포그래피와 ATELIER 조판으로 데스크톱 홈의 시각적 서명을 만든다. 모바일에서는 중복 masthead를 숨겨 작업 밀도를 유지하고 작품 마운트와 실제 스타일 썸네일로 구도를 이어간다. 장식 텍스트는 접근성 트리에서 제외하고 실제 h1은 유지한다. 헤더의 로고는 변경하지 않는다.
- 실제 공통 카드 작품을 마운트와 정렬선으로 진열한다. 앱 장식을 카드 렌더 범위 안에 넣거나 작품·얼굴·정보 위에 겹치지 않는다.
- 스타일 선택은 세 작품의 인덱스처럼 구성한다. 실제 썸네일·이름·선택 체크·pressed 상태를 유지하고 번호는 장식으로만 제공한다.
- 홈 프로젝트 영역은 하나의 보관 선반처럼 묶는다. 데스크톱에서는 섹션 이름 옆에 저장 입력을 배치하고, 모바일에서는 기존 세로 흐름으로 전환한다. 저장 폼의 얕은 Stone 표면과 비어 있는 목록의 구획선, 기존 표시 서체를 사용한다.
- 카드 만들기의 전역 우선순위를 유지한다. 저장 버튼은 입력이 유효하고 폼에 포커스가 있을 때만 채운다. 빈 입력으로 비활성인 저장 버튼은 강조하지 않는다.
- compact 스타일은 `data-compact` 안에서만 적용해 편집기 dialog에 섞이지 않게 한다. 상태·확인·취소·복구·출처 문구와 저장 동작은 유지한다.

기존 V3 라이브 홈 `75:1523`의 스크린샷을 요청했으나 브라우저가 반환된 이미지 URL을 차단했다. 이번 구도는 최신 사용자 피드백과 기존 V3 계약을 바탕으로 한 구현 파생 디자인이며 Figma exact로 표기하지 않는다.
