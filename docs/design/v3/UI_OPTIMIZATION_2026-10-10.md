# 디자인 계약 정리와 CSS 최적화 · 2026-10-10

사용자 요청: 설치한 테마를 UI/UX 디자인 MD로 정리하고 화면과 구현을 최적화.

## 현재 계약

루트 [DESIGN.md](../../../DESIGN.md)를 새 앱 UI/UX 단일 기준으로 작성했다. 설치된 bJMSkfGi Stone 원본 색상·반경·의미 별칭, 기존 서체, 화면별 행동과 우선순위, 밀도·반응형·접근성, 카드·데이터 경계와 CSS 유지보수 규칙을 기록한다. 프리셋이 지정하지 않은 폰트·레이아웃을 프리셋의 공식 값이라고 설명하지 않는다.

AGENTS.md, 프로젝트 README와 V3 인덱스에서 이 문서를 먼저 읽도록 연결했다. V3 마스터의 현재 앱 방향과 재사용 화면 프롬프트는 Stone으로 정정했다. 초기 종이·버건디·pill·2px 컨트롤 기록은 역사 자료로 명시했다. 편집기 900/901px 분기와 헤더 960px 분기를 구분했다.

## 구현 변경

- 사용하지 않는 전역 헤더 규칙 37개와 옛 앱 팔레트·표면 변수 13개를 제거했다. 실제 헤더는 기존 CSS Module을 사용하며 카드 폰트·토큰은 유지한다.
- 편집기에서 뒤의 동일/더 구체적인 규칙이 덮는 선언 481개를 제거했다. 조건·specificity·중요도·container fallback을 고려해 활성 규칙의 소스 순서를 유지했다.
- 사진 시작과 출력에서 사용되지 않는 이전 선언·빈 규칙을 제거했다. 스타일 페이지는 이미 중복이 없어 구조를 불필요하게 재작성하지 않았다.
- 홈의 헤더와 중복되는 큰 XIV masthead 및 세로 ATELIER 표기를 제거해 작업 영역을 앞으로 당겼다. 헤더 브랜드, 실제 작품 마운트, 세 스타일 인덱스와 선택 동작은 유지한다.
- 실제 기본 화면·편집기 정보/디자인 시트에서 확인한 10–11px 의미 있는 레이블을 12px 이상으로 올렸다. picker·비율·확인·필드 도움말의 작은 텍스트도 같은 기준으로 맞췄다. 작은 체크 기호·미니어처 기하와 카드 작품은 별도 경계를 유지한다.
- 사진 시작의 출처 문구는 작은 글자와 중첩 opacity를 줄이고 읽을 수 있게 했다. 공유 카드 출처 컴포넌트의 작품 스타일은 수정하지 않았다.

## 검증

- 타입 검사·전체 ESLint·프로덕션 빌드 통과. 전체 테스트 252개 통과, 실패 0개, 기존 아카이브 검사 29개 skip.
- 새 테마 계약 검사 4개: light/dark 별칭 역할, DESIGN.md에 기록된 원본 hash, 잘못된 혼합색·상수·destructive 역할 변경의 실패, 컴포넌트의 앱 색상 별칭 재정의 금지. 원본 파일 hash는 그대로 유지됐다.
- 최적화 전후 5개 경로 × 1440/390/320px × light/dark 30개 조건에서 실제 DOM 스타일을 수집했다. 카드 영역의 수집한 색상·배경·font-family 값은 동일했다. 홈 이외에서 색상·테두리·padding·margin·position 차이는 없고, 주된 UI 차이는 12px 글자 및 이에 따른 자연 크기·줄 높이·grid 치수였다.
- 모바일 전환의 인스펙터 닫힘 시점 때문에 한 기본 화면의 노드 수가 달랐다. 320px에서 사진 도구를 직접 열고 닫는 흐름을 확인했고, 정보·디자인 시트도 같은 열림 상태로 따로 비교했다. 소스 조건 삭제를 원인으로 단정하지 않았다.
- 최종 KO/EN/JA × 5개 경로 × 1440/390/320px × light/dark 90개 조건: 실제 viewport 값을 기록했다. 가로 넘침, 원본 토큰 별칭 불일치, 끊어진 접근성 ID, 보이는 의미 있는 비카드 UI의 12px 미만 레이블 없음.
- 편집기 정보·디자인 패널을 1440/390px에서 직접 열어 확인했고, 남아 있던 문양 색상 레이블도 최종 12px로 보정했다. 사용자 입력·저장 스키마·undo/redo·출력 코드는 변경하지 않았다.
