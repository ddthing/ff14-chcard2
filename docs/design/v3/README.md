**XXD 아이콘·일반 영감과 스크린샷 보호:** [XXD 레퍼런스 계약](./XXD_REFERENCE_CONTRACT_2026-10-13.md)에 지정된 UI 킷, 영감 자료로만 남기는 여덟 카드 레퍼런스, 스크린샷 재생성 금지 규칙을 기록한다. 여덟 레퍼런스와 거절된 콘셉트의 특정 스타일은 새 Figma 디자인을 제한하지 않는다. 일반 아이콘은 XXD, 직업 문양은 XIVAPI 원본을 사용한다.

**XXD 적용 검증:** [아이콘 구현·검증 기록](./XXD_ICON_IMPLEMENTATION_2026-10-13.md)에 원본 커밋·라이선스·별칭 처리, 일반 조작부·정보 픽토그램의 연결과 60조건 화면·PNG/WebP 출력을 기록한다.

**현재 편집기 구조:** [실제 Figma 제품 화면 대조와 구조 교정](./FIGMA_CHROME_REPAIR_2026-10-13.md)에 독립 도구 레일, 헤더 패널 접기, 평평한 레이어 목록, 중앙 캔버스, 아이콘 도구막대와 파란 선택 상태의 적용·검증을 기록한다.

**편집기 레이어 내비게이터:** [Figma 편집기 재구성과 반응형 검증](./FIGMA_EDITOR_REDESIGN_2026-10-13.md)에 실제 카드 항목 탐색, 3열·태블릿 드로어·모바일 시트 구조, 사진 자르기·포커스 경계와 QA 캡처를 기록한다.

**카드 조판·편집 사용성:** [Card Stage와 서체 편집 개선](./ATELIER_CRAFT_UPGRADE_2026-10-13.md)에 홈 직접 선택, 모바일 스타일 비교, 정보 서체 그룹, 간결한 글꼴 선택, 긴 문구 보존과 플레이스타일 용어 변경의 구현·검증을 기록한다.

**공통 내용·서체 편집:** [카드 직접 선택 편집기와 폰트 등록 정리](./UNIFIED_TEXT_EDITOR_2026-10-13.md)에 번호 위치 안내, 문구·서체 편집, 저장·출력, 폰트 생성기와 56px 모바일 헤더의 구현·검증을 기록한다.

**사진 마스크 가장자리:** [에디토리얼 검은 테두리 제거](./EDITORIAL_NO_INK_OUTLINE_2026-10-13.md)에 사용자 요청으로 확대한 잉크 밑그림을 제거한 변경과 원본 붓결·실제 PNG 출력 검증을 기록한다.

**배포 직업 아이콘:** [Git 배포의 아이콘 누락 수정](./DEPLOYED_JOB_ICONS_2026-10-13.md)에 배포본의 글자 대체·파일 404 원인, 동일한 빌드 플래그 전달과 환경 파일 없는 빌드 검증을 기록한다.

**네 모서리·사진 확장:** [반응형 장식과 모험가 기록 전체 상단 사진](./RESPONSIVE_CORNERS_FULL_BLEED_2026-10-13.md)에 다섯 비율의 장식 기하, 사진·종이 경계, 실제 PNG/WebP 출력 검증을 기록한다.

**사진 효과 후속 조정:** [원본을 보존하는 촘촘한 인쇄 질감](./SUBTLE_PHOTO_PRINT_2026-10-12.md)에 거친 망점과 배경 얼굴의 경쟁을 줄인 수정 및 검증을 기록한다.

**앱 UI/UX 단일 기준:** 루트 [DESIGN.md](../../../DESIGN.md)를 먼저 읽는다. 설치된 테마·컴포넌트·밀도·반응형·CSS 유지보수의 현재 계약이다. 아래 문서는 카드 계약과 변경 이력이며 과거 앱 시안이 현재 계약을 덮지 않는다.

**선택된 현재 홈:** 2026-10-11 사용자가 선택한 B · Card Stage를 실제 홈에 적용했다. [Card Stage 구현과 검증](./CARD_STAGE_IMPLEMENTATION_2026-10-11.md)이 현재 구도·스타일 선택·작업 영역의 적용 기록이다. 아래 이전 홈 구도는 이력으로 읽는다.

**후속 UX 수정:** 비판적 검토 후 사용자가 승인한 [홈 최우선 UX 수정](./HOME_PRIORITY_REPAIR_2026-10-11.md)에 화면 높이 대응, 앞쪽 작업 재개, 보관 대상 명시와 개인 비교 진입의 검증을 기록한다.

**엄격한 순차 검증:** [디자인 계약 순차 검증·수정](./STRICT_DESIGN_REPAIR_2026-10-11.md)에 한 항목씩 수정·빌드·실측·독립 검토 후 다음 항목으로 진행한 근거와 아직 실행하지 못한 환경 조건을 구분해 기록한다.

**이미지 출력 검증:** [이미지 내보내기 순차 검증](./EXPORT_VALIDATION_2026-10-11.md)에 45개 기본 조합, 형식·배율·상한·사진 조정의 실제 파일 검사와 검수 코드 제거 후 일반 빌드 확인을 기록한다.

**저장·복원 검증:** [저장·복원 순차 검증](./PERSISTENCE_VALIDATION_2026-10-11.md)에 새로고침·프로젝트 다시 열기·취소·undo/redo, 지운 부족의 복원 결함과 metadata 비교 누락의 수정·검증을 기록한다.

**사진·입력 경계 검증:** [사진·입력 경계 순차 검증](./INPUT_EDGE_VALIDATION_2026-10-11.md)에 실제 JPEG 업로드·복원, 긴 자유부대 이름의 행 침범과 프로젝트 이름의 이모지 길이 제한 수정, 실제 실행 범위와 도구의 한계를 기록한다.

**카드 내용 서체 교정:** [KO/EN/JA 카드 서체·크기 교정](./CARD_TYPOGRAPHY_REPAIR_2026-10-12.md)에 세 마스터의 같은 위계 정보값 정리, 65개 실제 출력과 작은 화면 90조건, 다국어 비교 이미지를 기록한다.

**우선순위별 후속 수정:** [UI 순차 수정·검증](./UI_PRIORITY_REPAIR_2026-10-12.md)에 각 항목의 수정·빌드·실물·독립 검토를 구분해 기록한다. 앞선 전체 검수는 수정 전 상태의 근거로 유지한다.

**현재 앱 테마:** 2026-10-10 사용자가 지정한 shadcn `bJMSkfGi`의 Stone 테마와 컨트롤 radius가 앱 UI 색상·모서리의 최신 기준이다. [적용 기록](./SHADCN_STONE_THEME_2026-10-10.md)을 먼저 확인한다. 이전 종이·버건디 앱 색상표는 V3 원본의 이력이며, 카드 마스터·서체·작업 흐름·접근성 계약은 계속 적용한다.

**테마의 엄격한 준수:** 이후 명시적 지시에 따라 [엄격한 Stone 준수](./STRICT_STONE_THEME_2026-10-10.md)를 우선한다. 원본 토큰을 직접 연결하며 보조색 혼합·별도 성공 팔레트·임의 모서리를 다시 추가하지 않는다.

**현재 화면·문구:** 이후 같은 날의 불필요한 설명 제거와 UI/UX 업그레이드 요청은 [Clean Studio](./CLEAN_STUDIO_2026-10-10.md)에 기록한다. 과거 홍보 문장·중복 도움말·단계 장식을 복원하지 않는다. 필요한 작업 레이블·상태·복구·접근성·출처는 유지한다.

**현재 홈 밀도:** 후속 요청에 따라 홈은 [Dense Home](./DENSE_HOME_2026-10-10.md)의 작업 중심 배치를 사용한다. 같은 짧은 문구를 유지하면서 미리보기·스타일·초안·프로젝트를 더 가까이 배치한다.

**현재 홈 위계:** 이후 시각적 위계 리팩토링 요청은 [홈 시각적 위계](./VISUAL_HIERARCHY_2026-10-10.md)를 따른다. 만들기·보조 행동·유틸리티의 강조를 구분하고, 초안 정보 그룹·제목 단계·작은 레이블의 가독성을 유지한다.

**현재 홈 정체성:** 특색이 부족하다는 후속 피드백에 따라 [홈 정체성](./HOME_IDENTITY_2026-10-10.md)의 타이포그래피·작품 진열·스타일 인덱스 구도를 사용한다. 밀도와 작업 위계는 유지한다.
