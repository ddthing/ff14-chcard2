## 모든 프롬프트에 붙이는 V3 공통 스타일

따뜻한 종이 배경, 짙은 잉크 본문, 절제된 버건디 강조색으로 XIV / ATELIER 프리미엄 카드 스튜디오의 일관성을 유지합니다. 편집 화면은 도구보다 실제 카드 미리보기를 중심에 두되, 조작 라벨·상태·선택 위계는 카드 장식보다 먼저 읽혀야 합니다. 넓은 여백, 단정한 기준선, 얇은 인쇄선, 절제된 장식과 명확한 제목/본문/라벨 타입 역할을 사용합니다. 구체 색상·폰트·크기·간격·반경·상태·모션은 토큰 문서를 따르고 화면마다 임의 값을 만들지 않습니다. 모바일은 390×844 및 안전 영역을 고려한 세로 흐름, 데스크톱은 1440px 폭을 위한 별도 그리드를 씁니다. 카드 프리뷰는 실제 선택 마스터, 입력 사진과 저장 데이터에서 렌더링합니다. 지원 로케일은 ko/en/ja이며 각 화면 안에서 언어를 섞지 않습니다.

캐릭터 데이터는 실제 카드 타입의 이름, 직업, 레벨, 월드, 데이터센터, 종족, 부족, 자유부대, 총사령부, 언어, 플레이스타일, 소개, 서비스·지역 필드만 사용합니다. 빈 값은 보간이나 추측으로 채우지 않습니다. 모든 주요 탭·버튼은 키보드로 조작 가능해야 하며 모바일 터치 목표는 44×44 CSS px 이상을 목표로 합니다. 포커스 표시, 읽을 수 있는 레이블, 상태 알림, 200% 확대와 가로 overflow 검사를 포함합니다.

## 모바일 화면 프롬프트

각 항목의 복사 문단을 공통 스타일·마스터 스펙·토큰과 함께 AI에 전달합니다.

### M01 · 홈

**목표:** 제품 가치를 바로 이해시키고 카드 만들기 또는 스타일 탐색을 시작하게 합니다. **입력:** 프레임 69:673, mobile_home.png, 실제 마스터 미리보기와 저장 초안. **스타일:** 공통 V3 스타일; 카드 쇼케이스는 선명하되 CTA보다 과하지 않게. **상호작용:** 새 카드 만들기, 스타일 보기, 저장 초안이 있을 때 이어서 만들기. **접근성:** 이미지 대체 설명, 명확한 heading/링크, 44px 터치 영역. **금지:** 허구의 후기·사용자 수·로그인·구독·동기화. **완료:** 새 작업과 초안 재개의 의미가 다르고 첫 CTA가 즉시 보입니다.

> 프레임 69:673을 기준으로 반응형 홈 경로 / 를 구현하라. 공통 V3 스타일과 실제 카드 미리보기를 적용하고, 제품 소개 다음에 새 카드 만들기와 스타일 보기의 위계를 둔다. 저장 초안이 있으면 실제 이름·마스터·저장 상태를 보여주는 이어서 만들기를 제공한다. 기존 경로와 초안 동작을 재사용하며 허구의 후기, 로그인, 동기화를 추가하지 않는다. 390×844에서 44px 탭 목표, 대체 텍스트, 세로 스크롤과 가로 넘침 없음을 확인하라.

### M02 · 스타일 선택

**목표:** 세 가지 패밀리를 공통 비율에서 비교시킵니다. **입력:** 프레임 69:785, mobile_templates.png; cinematic/editorial/id-card와 기본 4:5. **스타일:** 동일 크기의 실제 카드 미리보기와 읽기 쉬운 설명. **상호작용:** 카드 선택은 저장된 design.template을 갱신하고 편집 시작은 /editor로 이동. **접근성:** 키보드 선택, 선택 상태 의미 속성, 스타일 이름/설명. **금지:** 네 번째 가짜 템플릿·렌더러와 다른 스틸 썸네일. **완료:** 선택과 편집기 미리보기의 template ID·데이터가 같습니다.

> 프레임 69:785의 /templates를 구현하라. Cinematic Gold, Editorial Vermilion, Adventurer Record를 실제 공통 카드 렌더러로 동일한 4:5 비율에 보여주고, 선택 후 design.template과 초안을 갱신해 /editor로 연결한다. 저장 선택을 보존하고 카드 전체를 키보드로 고를 수 있게 하며 선택 상태를 보조 기술에 알린다. 임시 템플릿·별도 카드 구현은 금지한다. 390px에서 카드와 주요 행동을 읽고 선택할 수 있어야 한다.

### M03 · 사진 시작

**목표:** 로컬 이미지 또는 샘플로 편집을 시작합니다. **입력:** 프레임 69:1032, mobile_photo.png, JPG/PNG/WebP, 제공 샘플. **스타일:** 넉넉한 빈 상태, 점선 업로드 영역, 명시적인 선택 CTA. **상호작용:** 파일 선택/드롭, 샘플 선택, 성공 시 /editor. **접근성:** 파일 input의 이름, 버튼 입력 대안, 지원 형식 안내. **금지:** 원격 업로드나 선택 전 완료 표시. **완료:** 업로드 오류에서 현재 초안을 보존합니다.

> 프레임 69:1032의 /create를 구현하라. JPG·PNG·WebP 파일 선택과 드롭 및 실제 샘플 시작을 제공하고 처리는 브라우저에서 한다. 선택 전에는 완료 상태를 표시하지 않는다. 성공 후 실제 사진으로 편집기에 진입하고 실패하면 현재 초안을 남긴다. 파일 input과 버튼은 키보드 및 보조 기술로 쓸 수 있고 44px 탭 영역을 지킨다. 서버 업로드, 계정 보관과 지원하지 않는 형식 약속을 추가하지 않는다.

### M04 · 편집기 기본

**목표:** 카드, 저장 상태, 사진·정보·디자인 패널과 내보내기를 연결합니다. **입력:** 프레임 69:1073, mobile_editor.png, store/undo/redo 상태. **스타일:** 카드 중심 작업 공간, 상단 이름·저장·내보내기, 하단 탭. **상호작용:** 탭은 /editor 상태, undo/redo는 store, export는 /export. **접근성:** 탭과 패널 의미, 저장 상태 발표, 버튼 이름. **금지:** 샘플 카드 고정 표시, 하단 홈 영역이 컨트롤을 가리는 것. **완료:** 프리뷰와 초안·저장 상태가 동기화됩니다.

> 프레임 69:1073의 /editor 기본 상태를 구현하라. 상단 뒤로가기·캐릭터명·저장 상태·내보내기, 중앙의 실제 CardPreview, 사진·정보·디자인 패널과 undo/redo/맞춤을 연결한다. 같은 store와 공통 렌더러를 쓰고 복제 상태나 렌더러를 만들지 않는다. 저장·탭·버튼 상태를 접근성 의미로 노출하고 하단 조작이 안전 영역에 가려지지 않게 하라.

### M05 · 사진 조정

**목표:** 사진 위치·크기·밝기 조정과 교체. **입력:** 프레임 69:1148, mobile_editor_photo.png, 현재 image adjustments. **스타일:** 큰 프리뷰와 구별되는 수치/슬라이더. **상호작용:** 위치·크기·밝기·초기화·사진 교체를 store/history에 연결하고 연속 드래그는 history group 하나로 묶음. **접근성:** 슬라이더 레이블·현재값·키보드 조정. **금지:** 사진 픽셀 재생성, 화면 전용 보정. **완료:** 미리보기·저장·export 값 일치.

> 프레임 69:1148의 사진 패널을 구현하라. 원본과 사용자가 조정한 crop을 보존하면서 위치·크기·밝기와 초기화·교체를 기존 image adjustment store에 연결한다. 연속 슬라이더 드래그 하나는 한 번의 undo로 복원한다. 이름 있는 슬라이더와 로케일별 현재값·방향키 조정을 제공한다. 이미지 재생성이나 프리뷰만 다른 보정을 금지하고 새로고침 후 값과 export parity를 확인하라.

### M06 · 기본 정보

**목표:** 필수 캐릭터 정보를 정확히 고칩니다. **입력:** 프레임 71:1051, mobile_editor_info.png; name/job/level/world/dataCenter/race/clan/freeCompany. **스타일:** 입력 역할별 계층과 이름 전체 폭. **상호작용:** 기존 character update, 직업 선택 M09. **접근성:** 지속 label, 오류 연결, 키보드 이동. **금지:** 월드/DC 또는 종족/부족 혼동, 이름 자르기, 추정값. **완료:** 입력·초안·카드·export 데이터 일치.
