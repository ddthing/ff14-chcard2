# 60fps 참고 연구와 페이지 리디자인 · 2026-10-08

사용자 요청에 따라 홈, 스타일 갤러리, 사진 선택, 편집기, 내보내기를 개선했다. 기존 V3 토큰과 실제 카드 마스터를 기반으로 작업했다. 외부 참고 사례를 그대로 복제하거나 수상 품질·모든 기기에서 60fps를 보장하는 문서는 아니다.

## 참고 연구와 적용 판단

아래 링크는 참고 원본이며, 적용 열은 이 프로젝트에 맞춘 설계 판단이다. 단축 링크 대신 직접 도메인을 확인했다. 공개 페이지 설명을 확인한 사례와 실제 재생한 영상은 구분했다.

큰 장식과 지속적인 움직임을 추가하는 것보다, 사용자가 지금 선택한 카드와 다음 행동을 즉시 읽도록 구성하는 데 연구 결과를 사용했다.

## 페이지별 구현

| 페이지 | 결과 |
| --- | --- |
| 홈 `/` | 비대칭 편집형 구성: 소개, 큰 실제 카드, 세 스타일 선택. 저장된 초안 재개와 사진으로 시작하는 주요 행동을 구분 |
| 갤러리 `/templates` | 모바일·데스크톱 공용 컬렉션. 실제 마스터 세 개만 렌더. 가로 스냅, 중앙 카드 선택, 고정 시작 버튼. 명시적 스타일 클릭은 즉시 해당 카드로 이동해 중간 카드가 선택을 덮어쓰지 않도록 수정 |
| 사진 `/create` | 업로드 영역과 실제 카드 미리보기, 예시 사진 선택을 연결. 파일 선택 후 실제 파일명과 진행 상태를 표시 |
| 편집 `/editor` | 작업 도크·중앙 카드·설정 패널 구분. 모바일은 카드와 작업 탭을 먼저 배치. 상세 이미지 조절·글꼴 견본·효과는 필요한 때 펼침. 선택 밑줄과 패널 진입은 짧게, reduced-motion 분기 유지 |
| 출력 `/export` | 결과 카드, 형식·해상도·비율 선택, 주요 다운로드 행동의 위계 재구성. 고해상도 렌더와 인쇄 카드는 작업할 때만 생성 |

카드 마감은 실제 마스터 CSS에서 처리했다. 모험가 기록 카드의 밝은 사진에서도 상단 문구가 읽히도록 제한된 사진 상단 그라디언트를 추가했다. 인쇄 필드의 blur/opacity 하이라이트 애니메이션을 정적인 편집 안내로 바꿨다. 사용자 사진 필터, 마스터의 소재 역할, 출력 경로는 유지했다.

한국어 카드의 서버·레벨·종족·기본 문구, 사용자 입력 보존, 다섯 비율에서 카드 최상단에 놓이는 기록 깃발, XIVAPI 원본 직업 아이콘 정책을 유지했다. 이번 연구 작업 전 제거한 mask/SDF 파생 이미지 314개를 다시 도입하지 않았다. 원본이 없는 직업은 텍스트 대체를 사용한다.

## 병목과 리팩토링

- 이름 줄바꿈 계산: 동일한 이름/폭 계산에 64개 한도의 캐시 적용. 외부에 반환하는 배열은 독립 복사라서 캐시를 변경할 수 없다.
- 폰트 준비: 문서별 동일한 폰트·텍스트 요청을 합쳐 대기/완료 요청을 재사용. 실패·빈 결과는 재시도 가능. 사진 위치·배율 변경으로 같은 폰트를 다시 준비하지 않도록 요청 키를 렌더 텍스트와 서체에 한정.
- 마케팅 카드: 공유 `CardPreview`의 폰트 준비를 사용. 보이는 영역에 들어오면 한 번 생성해 반복 스크롤에서 마운트/해제를 반복하지 않는다.
- 갤러리: 이전 모바일·데스크톱 중복 컬렉션과 선택 미리보기의 전체 카드 인스턴스 7개를 공용 컬렉션 3개로 줄임. 홈은 큰 작품·스타일 썸네일과 저장 초안이 필요해 이번 검수에서는 5개이며, 홈의 카드가 하나라는 뜻은 아니다.
- 사진 드래그: 포인터 좌표 갱신을 animation frame당 한 번으로 합침. 종료·취소·해제 때 마지막 좌표를 먼저 적용한 뒤 히스토리 그룹을 닫음.
- 설정 패널: 필드별 store 선택자를 사용하고 Photo 작업에만 전체 사진 조절값을 구독. 저장 포맷과 320ms 저장 debounce, 잘못된/미래 버전 데이터 복구 경계는 유지.
- 내보내기: 폰트 준비·이미지 디코드·렌더러 import의 독립 대기를 겹치고, 광학 배치 준비는 MutationObserver와 제한된 polling 대체 경로를 사용.
- 출력 폰트 CSS: 같은 출처의 immutable WOFF2 리소스만 8MiB 한도 안에서 인코딩 결과를 재사용. 출력마다 필요한 CSS는 다시 구성하고 취소·실패 경계 유지.
- 인쇄: 고정 스냅샷의 측정 가능한 offscreen 카드를 생성하고 폰트·이미지·배치 준비가 끝난 뒤 브라우저 인쇄 호출. 중복 요청과 unmount 후 인쇄를 차단. 독립 코드 검토에서 발견한 최초 인쇄 준비 경쟁 조건을 수정하고 재검토 통과.

## 최종 검증

- 최종 `npm test`: 275 통과, 실패 0. 일부 카드 매트릭스 검사는 기존 렌더 증거를 검사하며, 이번에 전체 조합을 새로 출력한 것은 아님.
- 최종 `npm run lint`: 오류·경고 없이 통과.
- 최종 `npm run build`: 정적 다섯 페이지 생성 및 타입 검사 통과.
- 프로덕션 정적 빌드 브라우저: 한국어 다섯 페이지 × 320/390/768/1440px, 영어·일본어 다섯 페이지 × 320/1440px. 총 40개 구성에서 document 가로 넘침 없음.
- 모바일 갤러리에서 모험가 기록 선택 → 해당 template 생성 URL → 예시 사진 → 편집 경로 확인. 실제 마스터 수 3개 확인.
- 사진 드래그가 좌표를 변경하고 실행 취소 한 번으로 전체 드래그가 취소됨. 다시 실행 시 최종 좌표 복원. 검수 종료 전 원래 좌표로 복구.
- 한국어 이름 `연구용 모험가` 입력 후 새로고침 유지. 이 데이터는 127.0.0.1 검수 출처에서만 사용했고 사용자 localhost 초안은 보존.
- 실제 PNG·WebP 1× 파일을 저장하고 디코딩해 1080×1350 확인. PNG 1,316,218 bytes, WebP 143,118 bytes. PNG를 직접 열어 한국어 정보, 아이콘, 깃발을 시각 확인.
- 인쇄 준비 순서·취소·중복 방지 테스트와 독립 소스 검토 통과. 실제 OS 인쇄 대화상자에서 PDF 파일 생성은 이번에 수행하지 않았음.
- 실제 기기 전 범위의 FPS·메모리·전체 출력 조합 재측정은 수행하지 않았으며 보장하지 않음.
