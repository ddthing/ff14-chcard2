# 모션 레퍼런스 적용과 선택 목록 완전성 — 2026-10-12

사용자 요청: Motion Reference를 폭넓게 검토해 편집기의 움직임과 통일감을 개선하고, 직업 ‘전체’ 목록이 근접 딜러에서 끝나는 결함을 수정한다. 앱의 기준은 루트 DESIGN.md와 설치된 Stone 테마다.

## 레퍼런스 검토 범위

- 출처: [TakayuStudio Motion Reference](https://motion-reference.takayustudio.jp/).
- 사이트의 더 보기를 여섯 번 열어 표시된 782개 전체 목록과 64개 분류를 검토했다. DOM 기록은 목록 782개와 상단 추천 4개를 합친 786개다. 동일 명칭이 다른 분류에도 있으므로 이름의 고유 개수를 작품 개수로 사용하지 않는다.
- 목록의 원리와 적용 목적을 전체 분류한 뒤 탭 표시선, 아코디언, 누름 반응, 드롭다운 원점, 토글, 목록 순차 표시의 여섯 상세 예제를 집중 비교했다. 782개 모든 예제의 전 프레임·코드를 실험했다는 뜻은 아니다.
- 목록과 상세 읽기 기록은 `tmp/motion-reference-2026-10-12/catalog.json`, `details.json`에 보관한다. 제품에 원본 데모 코드를 복사하거나 새 라이브러리를 설치하지 않는다.

## 적용 원칙

| 원리 | 제품에 적용하는 방식 |
| --- | --- |
| 선택의 연속성 | 기존 탭 표시선과 홈 카드 이동을 유지하고, 템플릿 선택 반응은 짧은 공통 토큰으로 맞춘다. |
| 상세 펼침 | 지원 브라우저의 native details 높이·투명도 전환을 사용한다. 기본 open·키보드 의미와 열린 검색창의 표시 영역을 보존한다. |
| 패널 진입 | 인스펙터 전체와 각 섹션에 겹쳐 적용된 입장을 정리해 한 번의 짧은 전환으로 만든다. |
| 팝업의 소속감 | 보관함 native dialog에 작은 이동과 fade를 동기화한다. native 포커스·Escape·닫힘 흐름을 유지한다. |
| 누름·토글 반응 | 기존 press 기하와 상태 의미를 유지하며 같은 시간·곡선으로 상태가 바뀌게 한다. |
| 정보의 즉시성 | 검색 결과를 순차적으로 숨기거나 늦춰 표시하지 않는다. 모든 일치 결과를 즉시 탐색할 수 있어야 한다. |

모션은 기존 160/240/420/760ms 토큰 안에서 역할에 맞춰 사용한다. 예제의 긴 데모 재생 시간을 그대로 입력 컨트롤에 옮기지 않는다. 장식 반복, 입자, 글리치, 글자 해독, 포인터 추종, 과도한 튕김은 카드 편집 흐름에 추가하지 않는다. 실제 카드 렌더와 이미지 출력은 UI 모션 대상이 아니다.

## 직업 목록 결함과 수정

수정 전 실제 UI에는 ‘선택 안 함’과 14개 직업만 있었다. 마지막은 VPR/바이퍼였다. 원본 JOBS는 34개인데 공유 SearchablePicker가 `.slice(0, maxResults)`로 잘랐고 JobPicker는 14를 넘겼다. 스크롤 바깥에 나머지 직업이 있는 것이 아니라 DOM에 생성되지 않았다.

공유 컴포넌트의 결과 제한과 다섯 호출부의 maxResults를 제거했다. 직업 34개, 월드 90개, 종족 8개, 부족 16개, 총사령부 3개로 모두 작은 고정 목록이다. 기존 검색·필터·선택 해제·스크롤·키보드 이동 경로에서 전체 일치 결과를 사용한다. 서비스·지역·데이터 센터, 선택 종족에 따른 유효 필터는 유지한다.

이전 검증은 표시된 목록 마지막 행에 도달하는지만 확인해 원본 데이터와의 개수 차이를 놓쳤다. 이번에는 원본 ID 집합과 실제 목록 ID 집합, 역할별 결과 개수, 마지막 직업의 선택·Undo를 따로 대조한다.

## 추가로 발견한 결함

- 데스크톱 직업 팝업의 200% 폭이 인스펙터 왼쪽으로 벗어나 필터가 실제로 클릭되지 않았다. 팝업을 직업·레벨 행 전체 너비에 맞춰 다시 고정했다. 입력 화살표의 기준과 모바일 top-layer dialog는 유지한다.
- Escape 후 입력칸에 초점이 남으면 다시 클릭해도 열리지 않았다. focus와 click에 동기 open-state guard를 공유해 다시 열 수 있게 하고, 이미 열린 검색어는 지우지 않는다.
- 사용자가 ‘역할’과 ‘분류’의 중복을 추가 지적했다. 두 필터를 전체·방어·회복·근접·원거리 물리·원거리 마법·한정·제작·채집의 단일 분류로 합쳤다. roleId와 중복 필터 상태를 제거했으며 역할 이름은 검색 메타데이터로 유지한다. 앞선 이중 필터 검증 기록은 변경 전 근거로만 유지한다.

## 모션 구현과 검증

- 인스펙터 전환은 열린 상태에서 탭이 바뀔 때 한 번만 240ms로 실행한다. 각 폼 섹션의 중복 입장은 제거했다.
- 지속 마운트되는 native details에는 지원 조건 안에서 240ms 높이·투명도 전환을 적용했다. 4px clip margin으로 포커스 외곽선을 보존하고, 내부 선택창이 열리면 잘리지 않게 한다. 조건부 마운트하는 글꼴 상세는 기존 생명주기를 유지한다.
- 토글의 배경과 손잡이는 160ms로 동기화한다. 갤러리와 편집기의 템플릿 선택 선·배경은 160ms, 위치 전환은 240ms다.
- 편집기 ‘추가 도구 → 내 프로젝트’의 native dialog는 160ms fade와 240ms/4px 이동으로 열린다. 닫힘은 즉시 처리하며 native 포커스·Escape·복귀를 유지한다. 홈의 인라인 미리보기와는 별개다.
- 다국어·두 테마·1440/320px 12조건에서 전환 속성, 중복 입장 없음, 효과 Space/Enter 펼침·접힘, 토글 값 복원을 확인했다. 시작 프레임 기록의 높이 0은 펼침 전환 시작점이다. 별도 6개 언어/폭 완료 상태에서 opacity 1, 양수 내용 높이, 세 행의 동일 폭·x, 효과 간격 8px을 확인했다.
- 보관함 dialog 12개 언어/테마/폭 조건에서 전환 완료 후 화면 안 배치, 내부 초점, Escape 닫기와 trigger 초점 복귀를 확인했다. 모바일은 전체 화면이므로 4px 입장 이동 중 경계 차이와 완료 상태를 구분했다.
