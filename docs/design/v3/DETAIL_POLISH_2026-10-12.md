# 화면 디테일 마감 — 2026-10-12

사용자의 네 장 표시 이미지에 따른 후속 작업이다. 설치된 Stone 테마와 루트 DESIGN.md를 유지하며, 문제를 토큰·조판·기하·조작 의미로 나눠 확인한다. 시각적 완성도를 수상 여부로 표현하지 않는다.

## 수정 범위

1. 캔버스의 중복 이름/템플릿/실시간 캔버스 문구와 중복 미리보기 표시를 제거한다. 안전 영역은 기존 추가 도구로 이동한다. 실제 카드와 접근성 요약, 페이지 제목은 유지한다.
2. 세 스위치의 원이 트랙 안에 정확히 놓이게 하고 같은 조작/초점/켜짐 표현으로 통일한다. 색상·반경은 기존 토큰, 기능적 pill/circle만 사용한다.
3. 캐릭터 상세의 총사령부·언어·플레이 스타일·소개에 명확한 구획 간격을 둔다. 칩 조작 영역과 선택 제한은 유지한다.
4. 효과 항목을 하나의 그룹으로 정돈하고, 일반 디자인 패널에서 실험 B/C 선택을 제거한다. 기존 B/C 저장 값·렌더·선택 마스터 표시와 A 복귀는 유지한다.
5. 홈의 스타일 선택·만들기·비교 버튼을 같은 48px 높이로 정렬하고 그룹 사이 간격을 분리한다. 기본 만들기 강조와 Card Stage 구도는 유지한다.

## 구현 결과

- 완료. 캔버스 제목은 접근성 요약으로 유지하고 중복 시각 정보는 제거했다. 안전 영역은 추가 도구에서 조작한다. 샘플 안내가 없는 실제 업로드 화면은 제목용 빈 행도 만들지 않는다. 필드 초점 안내는 화면 밖 live status로 유지한다.
- 직업 문양·필름 입자·홀로그램 빛은 같은 native button 기반 `role="switch"`, `aria-checked`, 고유 제목·설명 참조를 사용한다. 트랙 42×24px, 원 18×18px, 상하·좌우 여백 3px, 켜짐 이동 18px로 기하를 통일했다. 실제 조작 영역은 기존 전체 행이다.
- 상세 정보의 그룹 간격은 24px, 칩 간격은 8px이다. 소개 뒤 출처 안내는 기존 4px 추가 여백을 포함해 28px이다. 효과 행의 제목·설명·아이콘·스위치 정렬과 표면을 통일했다.
- 최종 캡처에서 효과 버튼의 자동 폭이 문구에 따라 295.515625px/312px로 달라지는 결함을 추가로 발견했다. 기존 행에 `width: 100%`를 적용하고 효과 두 행 사이 8px sibling margin을 추가했다. details의 row-gap은 실측 간격 0px로 효과가 없어 제거했다.
- 일반 패널의 실험 B/C 진입은 제거했다. 기존 저장 카드의 B/C 렌더·현재 마스터 표시·A 복귀 경로는 유지한다.
- 홈의 세 스타일·만들기·비교 조작을 모두 최소 높이 48px로 맞췄다. 스타일과 행동 사이 간격은 데스크톱 24px, 모바일 16px이다. 761px 부근 고정 폭 열을 유연한 열로 바꿨다. 홈 헤더의 한국어 ‘홈’ 링크가 39.25px였던 추가 결함도 최소 폭 44px로 수정했다.

## 검수 경계와 최종 검사

- 사용자가 4324 화면을 사용하기 시작한 이후 데이터 변경 검수는 별도 4325 origin에서 실행했다. 4324의 카드 이름·사진·옵션을 이전 QA 값으로 복구하지 않았다.
- 파일 선택 응답이 제한 시간을 무시하고 611초 지연돼 추가 파일 선택은 실행하지 않았다. 실제 업로드 확인에는 4325의 임시 표시 버튼으로 기존 공개 샘플을 File로 만들고 정상 `acceptImage → prepareImageFile → replaceUploadedImage` 경로를 실행했다. DOM/CSS만 바꾼 업로드 상태가 아니다. 버튼과 query 분기는 검수 후 제거했다.
- 임시 업로드 코드 제거 후 editor-workspace.tsx SHA-256은 검수 전 최종 소스와 같은 `858AEC26E81A9E3790270EC0693E8552D2006DF9C4CC612D210840C3D1A67D5B`이다. 최종 빌드의 src/out/dist에 임시 export·보관함 실패·업로드 검수 문자열이 없다.
- lint·typecheck 통과. runtime test 269개 통과·실패 0, 역사적 렌더 아카이브 29개 skip. 임시 코드 제거 후 프로덕션 빌드 통과. 독립 소스·실측 기록 검토 통과.
- 원본 테마 SHA-256은 `E25912D9A98152C90EC17352DBE22A6573928522063C807DDD3CCDA906C55F92`로 유지했다. 카드 렌더·내보내기·데이터 모델을 변경하지 않았다.
- OS 동작 줄이기·강제 색상·실제 스크린리더·소프트 키보드는 실물 검증하지 않았다. 일반 모션·소스 검증과 구분하며 전체 WCAG 인증으로 표현하지 않는다. 조건부 create/export 오류와 삭제 hover의 검증 범위는 [우선순위 수정 기록](./UI_PRIORITY_REPAIR_2026-10-12.md)의 단계 10을 따른다.
