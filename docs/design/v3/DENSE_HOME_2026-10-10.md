# Dense Home · 2026-10-10

사용자 요청: 현재 홈을 밀도 있는 화면으로 업그레이드.

## 변경

- 큰 제목·42rem hero 높이·넓은 빈 간격을 줄이고, 제목/액션·스타일·초안을 미리보기 옆의 작업 영역으로 모았다. 데스크톱 대표 카드는 실제 공통 렌더러를 약 296px 폭으로 표시한다.
- 모바일도 카드 폭·여백을 줄이고 세 스타일와 초안으로 빠르게 이어지게 했다. 라벨 12px 이상, 주요 조작 영역 44px 이상을 유지한다.
- `LocalProjectLibrary`에 선택적인 `compact` 표시를 추가하고 홈에서 활성화했다. 중복 page gutter와 큰 상하 패딩을 제거하고 제목·저장 폼·목록을 더 촘촘히 배치했다. 기본 보관함과 편집기 dialog는 기존 표시를 유지한다.
- 이전에 제거한 설명·배지·홍보 문구를 복원하지 않았다. Stone 테마·서체·선택 동작·샘플 표시·초안과 저장·카드 렌더러 및 출력 경계는 유지한다.
- 모바일의 일반 저장 상태는 visually-hidden으로 남겨 live region을 유지하고, 저장 오류는 계속 표시한다.

V3 라이브 Figma 홈 `75:1523`을 참고했고, 이번 사용자 요청으로 이전 Clean Studio의 넓은 홈 구도를 더 촘촘히 재구성했다.

## 같은 데이터로 비교한 배치

별도 로컬 검수 origin `127.0.0.1:4323`에서 같은 초안과 저장 프로젝트 한 개를 사용했다. 현재 사용 중인 `4322`의 저장 데이터를 바꾸지 않았다. 기준은 1440×900 CSS px이며 아래는 문서 상단에서의 실제 위치다.

| 영역 | 이전 Y | 변경 후 Y |
| --- | ---: | ---: |
| 스타일 제목 | 834px | 259px |
| 프로젝트 제목 | 1222px | 526px |
| 프로젝트 저장 폼 | 1288px | 566px |
| 첫 프로젝트 행 | 1506px | 684px |

문서 전체 높이는 약 1829px에서 917px로 줄었다. 미리보기·세 스타일·초안·저장 폼·첫 프로젝트 행이 데스크톱 첫 화면 안에 들어온다. 모바일에서는 현재 초안이 있어도 스타일·초안·프로젝트 제목까지 첫 화면에서 찾을 수 있다.

- TypeScript·ESLint·프로덕션 빌드 통과. 전체 테스트 248개 통과, 기존 아카이브 검사 29개 skip.

- 스타일 선택 후 만들기 링크의 선택값 전달, compact 목록의 미리보기 열기와 이름 있는 영역 연결 확인.

- 최종 모바일 AX에서 “저장됨” 상태가 유지되고 `display:block`, 1px clipped live region임을 확인했다. 다크 홈과 초안이 없는 홈에서도 가로 넘침 없음.
- 편집기의 보관함 dialog에는 compact 클래스가 적용되지 않고 기존 제목 크기·폭을 유지했다. Escape 후 원래 트리거로 포커스 복귀 확인. 브라우저 error 로그 0개.
