사용자의 `ff14-chcard2 하이엔드급으로 만들어줘` 요청에 따라 기존 Card Stage 방향을 유지하며 홈부터 결과 저장까지의 시각적 위계를 정리했다. 루트 DESIGN.md와 연결된 실제 Figma Card Stage B 프레임을 확인했다.

## 변경

- 홈: 중립 Stone 카드 무대와 제작 도크를 한 표면으로 묶었다. 실제 스타일 순서와 선택선을 표시하고 제목 옆에 비교 링크를 배치했다. 카드 자체의 렌더링은 그대로다.
- 공통 헤더: 브랜드·내비게이션·설정을 세 영역으로 정렬하고 브랜드 글자 기준선을 맞췄다.
- 보관함: 홈에서만 제목·보관 대상과 저장 폼을 두 열로 정리했다. 모바일은 한 열이며 편집기의 보관함 대화상자는 영향받지 않는다.
- 스타일: 제목과 비교 모드를 묶고, 겹친 선택 외곽선을 단일 경계와 기존 체크로 정리했다. 선택 정보와 시작 행동을 같은 영역에 모았다.
- 사진: 과도하게 큰 업로드 영역을 줄이고 업로드·샘플 선택과 실제 공유 렌더러의 카드 미리보기를 함께 배치했다. 업로드 전에는 샘플 카드임을 표시한다. 중복 CSS 규칙을 통합했다.
- 출력: 카드 확인 영역과 340–360px 설정 열의 위계를 정리했다. 완료 화면의 실제 파일명·픽셀 크기·형식·Blob 용량을 묶고 출력 전후 카드 비율을 일치시켰다.
