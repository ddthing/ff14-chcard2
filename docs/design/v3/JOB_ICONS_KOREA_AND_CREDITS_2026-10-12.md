# 직업 아이콘·한국 월드·저작권 표시 — 2026-10-12

사용자가 표시한 NIN 약칭, 마스크의 검은 가장자리, 한국 월드 적용 실패, 선택기 아이콘 크기 차이를 각각 확인했다. 원본 Stone 테마와 카드·저장 경계를 유지한다.

## 원인과 수정

- **큰 직업 문양:** 큰 문양의 SVG 전용 제한 때문에 검증된 256px Ninja PNG가 있어도 NIN 약칭으로 대체됐다. 승인 SVG를 우선하고, 명시적으로 큰 문양 사용이 승인된 256px 이상 원본 PNG만 fallback으로 허용한다. 파일 누락을 숨기기 위해 새 그림을 만들지 않는다.
- **선택기 크기:** 바깥 20px 상자는 같지만 원본의 투명 여백과 기존 광학 배율 때문에 보이는 그림 크기가 달랐다. 원본 알파 128 기준 실제 그림의 긴 변을 18px로 맞추는 picker 전용 배율을 기록했다. 카드·출력의 기존 광학 배율과 원본 파일은 유지한다.
- **검은 마스크 가장자리:** 위치 오류가 아니다. `.brushUnderlay`가 사진과 같은 brush clip을 사용하면서 1.018배로 커져 어두운 잉크 테두리를 의도적으로 드러낸다. 1:1 구도에서는 일부 붓 형태가 카드 가장자리까지 이어진다. 사진 원본의 검은 가장자리가 새는 현상이 아니며 효과를 임의로 제거하지 않았다.
- **한국 월드:** 한국 월드의 정상 데이터에는 지역·데이터 센터 ID가 없다. 선택 패치를 적용한 뒤 null 데이터 센터 처리에서 월드까지 지우던 오류였다. 명시적으로 선택한 정식 월드가 있으면 유지하고, 데이터 센터만 직접 지우는 기존 동작은 유지한다.
- **하단 문구:** 요청한 상표 안내와 비공식 팬 프로젝트·제휴 관련 문구 및 구분점을 제거했다. 기존 글로벌/한국 저작권 줄만 남긴다. 카드의 `© SQUARE ENIX` 표시는 동일하다.
- **문양 배치:** 실제 정사각형 PNG에서 마지막 정보 행과 문양이 가까운 결함을 추가로 발견했다. 1:1 문양 시작점을 68→72%로 내렸다. 16:9는 시작점 71%, 문양 8.5cqi, 내부 간격 .35cqi로 조정해 저작권과도 여백을 확보했다. 사진·붓 모양·정보 서체는 변경하지 않았다.

## 원본과 지원 범위
