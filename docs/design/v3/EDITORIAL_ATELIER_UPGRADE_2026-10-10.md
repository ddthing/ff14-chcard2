# Editorial Atelier UI·모션 업그레이드 · 2026-10-10

사용자 요청: 전체 UI/UX 디자인 후보를 먼저 검토한 뒤 Editorial Atelier 방향과 풍성하되 절제된 모션으로 구현 시작. 추천 조합의 실제 사진 스타일 비교 및 기기 내 작품 보관함을 함께 구현. 카드 자체의 아트 디렉션 재설계는 후속 단계로 남긴다.

## 구현 범위

- 홈: 종이·잉크·버건디, 등록된 서체를 유지하는 작품 중심 편집 구도. 대표 작품 주변의 중첩 프레임을 줄이고 시작 액션과 스타일 탐색, 세 스타일 선택, 초안 재개를 정리했다. 한국어 제목은 1440px와 390px에서 두 줄로 조판한다.
- 사진 시작 및 출력: 열린 작품 스테이지, 얇은 구분선과 단정한 조작부. 업로드 완료 시 실제 사진으로 스타일 비교하는 경로를 제공한다.
- 스타일 비교: 예시 / 내 카드 비교를 명시적으로 전환한다. 개인 비교는 같은 사진·정보·보정·현재 비율을 복사해 세 마스터로 렌더링하며, 탐색 자체는 초안을 변경하지 않는다. 적용 액션만 기존 저장소의 스타일·마스터 레이아웃을 바꾼다.
- 편집기: 평평한 작업대, 정돈된 인스펙터와 도구. 입력 대상은 카드 외부의 현지화된 힌트로 안내한다. 도구 시트를 바꿔도 같은 CardPreview 인스턴스를 유지한다.
- 프로젝트 보관함: 홈의 `내 프로젝트`, 편집기 `추가 도구`에서 진입. 이름 저장, 미리보기, 이름 변경, 복제, 재열기, 확인 후 삭제. IndexedDB의 요약 / 사진 포함 카드 저장소를 동일 트랜잭션으로 관리한다. 현재 자동 저장 초안은 독립적으로 유지한다.
- 프로젝트 전환: 현재 작업을 보관한 뒤 열거나, 명시적으로 바꾸고 열도록 선택한다. 복원한 사진 메타데이터와 편집 기록을 유지하고 초안 저장 성공 이후 이동한다. 저장 실패·용량·읽기 오류를 완료로 표시하지 않는다.

## 모션과 경계

첫 등장에는 짧은 순차 전개, 작품 선택에는 유한한 이동·교체, 도구와 시트에는 기존 120/180/220ms 토큰, 보조 액션에는 짧은 hover/press 반응을 사용한다. 사진 조정과 입력 업데이트는 즉시 반영한다. UI 모션이 인쇄 카드 및 숨겨진 출력 표면으로 들어가지 않는다.

동작 줄이기에서는 움직임을 끄고 선택·오류·저장 상태를 유지한다. 모바일 시트 및 프로젝트 모달은 Escape와 포커스 복귀를 제공한다. 프로젝트 모달 안에서는 편집기의 전역 단축키를 억제한다. 홈·사진 시작의 중복 main landmark도 정리했다.

기존 카드 마스터·CardPreview·출력 파이프라인·XIVAPI 원본 자산·테마 분리·언어 및 기존 필드를 보존한다. 새 계정, 서버 업로드, 기기 간 동기화 및 외부 배포는 포함하지 않는다. 기존 작업 트리의 다른 변경을 되돌리지 않았다.

## 검수 중 수정

- 같은 사진 URL의 프로젝트를 열 때 대상 파일명/MIME을 잃던 동작: 명시적으로 전달된 메타데이터를 우선하고, 생략한 경우에만 기존 메타데이터를 유지하도록 좁게 수정했다.
- 긴 이모지 프로젝트 이름: UTF-16 잘림과 코드 포인트 검증의 단위를 통일하고 80개 이모지 이름의 저장/목록/읽기 회귀 검사를 추가했다.
- 개인 비교의 보조 링크 폭: 주요 버튼의 퍼센트 최소 너비로 생긴 넘침을 제거하고 좁은 화면에서 액션을 쌓는다.
- 비교 카드 비율: 여백 있는 외부 스테이지와 실제 카드 비율을 분리해 CardPreview를 늘리지 않는다.
- 초기 모바일 선택: 의도한 작품을 먼저 가운데 배치하고 스크롤 관찰을 시작한다.
- 모달 Escape: More tools와 전역 편집 단축키가 네이티브 dialog 닫기를 가로채지 않게 했다.

## 실제 검증

- TypeScript 검사, ESLint, 최종 프로덕션 빌드 통과. Next.js의 로컬 16.4.0 문서를 확인했다.
- `npm test`: 248 통과, 0 실패, 과거 렌더 아카이브 검사 29개 명시적 skip.
- 프로덕션 정적 빌드: 5개 경로 × KO/EN/JA × 320/390/768/1440px = 60개 화면에서 가로 넘침·브라우저 실행 오류 없음.
- 다크 + 동작 줄이기: 5개 경로에서 가로 넘침 없음, 실행 중 이동 애니메이션 0개. 총 화면 검사 65개.
- 개인 비교: 3개 마스터 × 5개 비율 × 3개 로케일 = 45개 실제 카드 렌더. 이름 존재, 실제 가로세로 비율, 페이지 가로 넘침 확인. 15개 비교 화면을 새로 캡처했다.
- 실제 동작 18개: 사진 업로드/메타데이터, 비교 탐색의 불변성, 스타일 적용의 데이터 보존, 프로젝트 저장/reload/이름 변경/복제/미리보기/전환/reload/삭제, 모바일 모달 크기, Escape 및 포커스 복귀, 실제 PNG·WebP 다운로드를 확인했다. 두 출력은 파일을 디코딩해 1080×1350을 확인했다.
- 모바일 편집 도구 세 가지: 시트 경계, Escape, 포커스 복귀 및 같은 카드 DOM 인스턴스 유지 확인.
- 독립 코드 검토에서 저장 관련 두 지적을 수정하고 재검토에서 해결을 확인했다.
- 변경한 경로의 `git diff --check` 통과. 작업 이전의 릴리스 HTML에 있던 trailing whitespace는 이 범위에서 수정하지 않았다.

전체 45개 출력 파일·모든 배율·실제 휴대폰 OS 키보드의 검사를 수행했다는 뜻은 아니다. 카드 재설계 없이 UI 및 새 비교/보관 흐름을 검증한 범위다.
