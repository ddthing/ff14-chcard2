## 구현 방향

Stone 테마와 등록된 서체를 유지하고 실제 카드와 작업을 먼저 보여준다. 장식용 수식어·단계 카운터·중복 설명·반복 배지·홍보성 문장을 제거한다. 색상만 바꾸거나 글을 CSS로 감추는 방식이 아니라 렌더링 구조에서 불필요한 요소를 덜어낸다.

- 홈·스타일: 큰 작품, 짧은 제목, 직접 선택, 제작·비교 액션과 초안 재개.
- 사진: 파일 선택·드롭, 실제 사진/샘플, 짧은 파일 제한과 처리 상태.
- 편집: 카드와 현재 도구, 명확한 필드 이름과 선택·저장 상태.
- 출력: 실제 카드·형식·픽셀·파일과 다운로드/편집 행동.
- 보관함: 하나의 제목과 저장·목록·재열기, 간결한 로컬 저장 표시.

오류와 회복 액션, 삭제/덮어쓰기의 결과, 지원 파일과 크기, 저장·다운로드의 실제 상태, 샘플 구분, 접근성 레이블과 법적 고지는 작업에 필요한 정보로 유지한다. 카드 렌더러·직업 원본·데이터·저장·history·export 경계를 보존한다. 어워즈 수상 또는 외부 심사를 받았다고 표현하지 않는다.

V3 라이브 Figma 홈 `75:1523`을 원래 구도·기능 참고로 확인했다. 이번 사용자의 정리·업그레이드 요청과 직전 Stone 승인에 따른 제품 개선이므로 과거 홍보 문장과 종이/버건디 앱 색상을 다시 가져오지 않는다.
