# XXD 아이콘·카드 레퍼런스와 스크린샷 보호 계약

기준일: 2026-10-13. 사용자가 지정한 UI 킷과 여덟 카드 레퍼런스의 출처·일반 영감을 기록한다. 여덟 카드 레퍼런스는 영감 자료이며 새 Figma 카드 디자인을 제한하거나 지시하지 않는다. 사용자가 거절한 2026-10-13 카드 콘셉트와 이전 와이어프레임의 특정 스타일도 새 디자인의 출발점이 아니다. 현재 탐색 제안은 [새 카드 재설계 기록](./FIGMA_CARD_RESET_2026-10-13.md)과 완료되어 시각적으로 확인된 [Figma 보드](https://www.figma.com/design/v3cQNL7K8NpuT9Xhhk1KYW?node-id=7-25)의 ELECTRIC EDITORIAL, AMBIENT PRINT, FIELD NOTE다. 이는 제안 단계이며 제품 변경이나 다섯 비율 전체의 검증이 아니다. 앱 구조·Stone 테마는 [루트 DESIGN.md](../../../DESIGN.md), 승인된 카드 마스터·정보·비율·출력은 [V3 마스터 스펙](./MASTER_DESIGN_SPEC.md)을 함께 따른다.

## 원본 스크린샷을 지키는 최우선 규칙

**사용자가 첨부한 FINAL FANTASY XIV 스크린샷은 절대 재생성하지 않는다.** 원본, 크롭, 캐릭터 추출물과 장면을 재구성하는 설명을 이미지 생성/편집 모델에 전달하지 않는다. image-to-image, 인페인팅·아웃페인팅, 생성형 채우기·업스케일, 얼굴·장비·캐릭터 재그림, 없는 게임 배경 합성은 금지한다. 외부 스킬의 원문 프롬프트와 기본 실행 방식이 이 규칙을 덮을 수 없다.

사용자는 카드 배경·프레임·종이/재료 질감·장식용 **독립 AI 생성 비트맵 소스**를 명시적으로 승인했다. 생성은 사용자 스크린샷, 크롭, 캐릭터 추출물, 장면 재구성 설명, 또는 사용자 데이터를 입력으로 삼지 않고 수행한다. 소스에는 스크린샷, 사용자 이름/정보, 직업 아이콘을 포함하거나 굽지 않는다. 앱은 생성 장식 소스와 원본 스크린샷 별도 이미지 레이어, 수정 가능한 네이티브 텍스트, 기존 XIVAPI 원본 직업 아이콘을 합성하며, 사진은 생성된 카드 이미지에 굽지 않는다. 이전의 코드·벡터·기존 재료 전용 표현은 생성 장식 소스에 대한 금지가 아니다.

제작 흐름은 **사진 없이 카드 레이아웃 및 장식 소스 준비 → 사용자가 로컬 파일 선택 → 원본을 별도 이미지 레이어에 배치 → 같은 렌더러로 미리보기·출력**이다. 서체와 실제 정보는 수정 가능한 앱 요소로 유지한다.

기존의 사용자 조절 위치·배율·크롭, 마스크와 결정론적 인쇄 효과는 로컬 렌더 동작으로 유지한다. 새 레퍼런스를 적용한다는 이유로 원본에 필터·색 보정을 추가하지 않는다. 원본 소스와 사용자 조정값, 초기화, undo/redo, 저장·복원, preview/export 일치와 저작권 고지를 보존한다. 이 문구는 사용자의 명시적 제한을 구현한 것이며 Square Enix 공지의 법적 범위를 새로 해석한 결론은 아니다.

현재 업로드 준비는 브라우저 canvas에서 크기를 제한하고 이미지를 재인코딩한다. 이 결정론적 전처리는 생성형 재생성과 다르며 업로드 파일의 바이트를 그대로 보관한다는 뜻은 아니다. 이번 지침 갱신은 기존 전처리를 변경하거나 원본 파일 보관 기능을 새로 구현한 작업이 아니다.

## 아이콘 적용

- 소스: [nevertoday/xxd-ui-kit](https://github.com/nevertoday/xxd-ui-kit), `packages/xxd-icons`.
- 일반 조작 아이콘과 카드 정보 픽토그램에 원본 24×24 격자·1.5 선 두께를 사용한다. 원본 경로를 새로 그리거나 앱마다 다른 선 두께를 넣지 않는다.
- 저장소 안에 고정한 소스와 공통 타입 어댑터를 사용한다. 원본 커밋·파일·해시·MIT 고지를 보관하며 실행 시 외부 CDN에서 아이콘을 받지 않는다.
- 기존 버튼 크기, 의미 있는 레이블, 포커스와 선택 상태를 유지한다. 장식 SVG는 접근성 트리에서 숨기고 조작 이름은 버튼·필드가 제공한다.
- 직업 표식은 기존 resolver가 승인한 XIVAPI 원본이다. XXD로 교체하지 않는다. 제품 로고와 인쇄 프레임·사진 마스크는 일반 조작 아이콘이 아니다.
- XXD의 토큰·React 컴포넌트·테마 전체를 가져오는 작업은 이 아이콘 요청에 포함하지 않는다.

## 카드 레퍼런스 — 영감 자료만

여덟 레퍼런스는 참고용 영감으로 남긴다. 사용자가 거절한 [세 카드 콘셉트](./DISTINCT_CARD_CONCEPTS_2026-10-13.md) 및 [생성 소스](./GENERATED_CARD_SOURCES_2026-10-13.md)는 REJECTED 상태이며 현재 Figma 보드의 출발점이 아니다. 새 보드의 세 방향은 해당 거절된 스타일과 별개 제안이다. 필요하다면 장식용 독립 생성 소스를 사용할 수 있지만, 이 허용은 특정 스타일을 요구하지 않는다. 사용자 사진·크롭·캐릭터·장면 설명·정보를 생성 입력으로 전달하지 않으며, 새 디자인에서도 사진·네이티브 텍스트·원본 XIVAPI 직업 아이콘의 경계는 유지한다.

아래 표는 과거 제안 기록이다. 후속 카드 제작 지침이나 새 Figma 디자인의 출발점으로 사용하지 않는다.

| 방향 | 참고 패널 | 사진 슬롯·정보 배치 | 지켜야 할 점 |
| --- | --- | --- | --- |
| 종이 콜라주 | 225 + 228 | 큰 원본 사진, 한쪽 종이 여백의 이름·소개·기본 정보 | Editorial의 기존 사진/종이 구도를 기반으로 종이·테이프는 사진 밖에 한정한다. 얼굴·이름을 가리는 스티커 더미를 만들지 않는다. |

249와 242는 주로 보조 재료·여백 연구에 사용한다. 본래 피사체 변환이 핵심인 레퍼런스를 억지로 사진 변환 기능으로 옮기지 않는다. 각 방향은 1:1·4:5·3:4·9:16·16:9의 사진 슬롯과 글자 영역을 독립적으로 배치한다.

## 일반적인 사진 안전 경계 메모

아래는 과거의 안전 경계 메모이며 새 Figma 디자인의 구도·재료·서체를 지정하는 프롬프트가 아니다. XXD의 여덟 패널은 필요에 따라 일반적인 영감 자료로 살펴볼 수 있다. 거절된 세 콘셉트의 특정 스타일은 가져오지 않는다.

> 필요하면 사용자 입력 없이 독립된 배경·프레임·종이/재료·장식 비트맵 소스를 생성할 수 있다. 사용자 FFXIV 스크린샷, 크롭, 캐릭터 추출물, 장면 재구성 설명 또는 사용자 데이터를 이미지 생성/편집 모델에 입력하지 말라. 생성 소스에 스크린샷·사용자 정보·직업 아이콘을 굽지 말라. 스크린샷 이미지 레이어·수정 가능한 네이티브 텍스트·승인된 XIVAPI 직업 아이콘을 따로 합성하라. 이미지 재생성·인페인팅·아웃페인팅·생성형 채우기·업스케일·캐릭터 재그림은 금지한다. 기존 로컬 upload/store/history와 단일 CardPreview/export 렌더러, 실제 필드·사용자 팔레트·서체·저작권 고지와 다섯 비율·세 로케일을 보존하라.

## 출처·스킬 사용

[UI 킷의 MIT 라이선스](https://github.com/nevertoday/xxd-ui-kit/blob/main/LICENSE)와 패널 저장소의 라이선스는 다르다. 패널 README는 스킬·프롬프트·스크립트·샘플의 라이선스를 PolyForm Noncommercial 1.0.0으로 명시한다([225의 원문 안내](https://github.com/nevertoday/xxd-panel-225/blob/main/README.ko.md#라이선스), [공식 라이선스 본문](https://polyformproject.org/licenses/noncommercial/1.0.0/)). 패널의 샘플 비트맵·원문 프롬프트·스크립트를 앱에 복사하지 않는다. 이 문서는 사용자가 지정한 시각 원리를 정리하고 기존 제품에 독자적으로 구현할 범위를 정한다.

이번 작업에는 이 패널 스킬들을 설치하거나 호출할 필요가 없다. 후속 작업에서 스킬이 필요하면 실행 경로를 먼저 읽고 위 보호 문단을 포함한다. 원본 사진을 생성 모델의 참조로 넘기는 스킬은 사용자 스크린샷에 실행하지 않는다.

## 검수

1. 원본 사진 소스·조정값이 upload → 초안 → 복원 → 렌더 → export에서 이어지는지 확인한다. 출력 리사이즈·크롭 때문에 파일 전체 바이트가 달라지는 것을 이미지 재생성과 혼동하지 않는다.
2. 사진·크롭·캐릭터 추출물이나 장면 재구성 정보를 생성 모델로 보내는 코드·도구 호출이 없는지 검사한다.
3. photo slot의 face clearance, 필수 데이터, 긴 KO/EN/JA 이름과 다섯 비율을 확인한다. 생성된 카드 스틸로 실제 renderer를 대체하지 않는다.
4. 일반 XXD 아이콘의 원본 기하·출처·라이선스와 접근성, XIVAPI 직업 원본 경계를 각각 확인한다.
5. 타입 검사·ESLint·관련 회귀 테스트·프로덕션 빌드를 실행하고 실제 범위를 기록한다. 재생성 금지 위반은 [QA 가이드](./AI_QA_REPAIR_GUIDE.md)의 P0다.
