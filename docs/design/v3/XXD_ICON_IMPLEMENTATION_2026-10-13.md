# XXD 아이콘 적용과 레퍼런스 지침 갱신

2026-10-13 사용자 요청에 따라 지정한 XXD UI Kit 아이콘을 적용하고 여덟 카드 참고 자료와 스크린샷 보호 경계를 정리했다. 작업 전부터 존재하던 편집기·서체 변경을 유지했으며 새 카드 템플릿·사진 재생성 기능은 추가하지 않았다.

## 적용

- 원본: [nevertoday/xxd-ui-kit](https://github.com/nevertoday/xxd-ui-kit), 커밋 `a7a811eecff45538bbc950d1e57ce4cd8efeb674`의 `packages/xxd-icons/src/nodes.js`.
- 로컬 소스의 Git blob SHA는 `5cbd041fb42189fa55ddce59a7989d3d2cfdb432`로 원본과 일치한다. `licenses/xxd-icons/`에 MIT 라이선스와 출처를 보관했다.
- 공통 `AppIcon`은 24×24 / 1.5 stroke / round cap / miter join으로 원본 노드를 렌더한다. 직접 이름과 열 개의 원본 별칭을 해석한다.
- 편집 도구, 메뉴·테마, 대화상자 닫기, 상태 체크, 화살표·다운로드·재시도 표시, 카드의 아홉 정보 픽토그램을 연결했다.
- 원본 세트에 없는 손·줌·안전 영역 조작은 `Grip`, `Plus`/`Minus`, `Square`에 매핑하고 기존 의미 있는 조작 이름을 유지했다.
- XIVAPI 직업 문양·직업 fallback·제품 로고·프레임·사진 마스크는 기존 경로를 유지한다. CSS 크기·버튼·라우트·저장·출력 동작을 보존했다.

## 지침

[XXD 레퍼런스 계약](./XXD_REFERENCE_CONTRACT_2026-10-13.md)에 225·266·249·251·255·242·227·228의 구도·소재·여백·조판 적용 범위와 제외할 피사체 재그림을 기록했다. 후속 방향은 종이 콜라주, 장면 기념 인쇄물, 모험가 아카이브다. 이번 변경으로 이 방향들을 새 템플릿으로 출시한 것은 아니다.

`AGENTS.md`, 루트 `DESIGN.md`, 카드 계약, 마스터 스펙·토큰·공통 제작 프롬프트·QA 가이드에 같은 보호 규칙을 반영했다. 사용자 스크린샷과 크롭·캐릭터 추출물을 생성 모델에 전달하거나 장면을 재구성하지 않는다. 빈 사진 슬롯에 기존 로컬 원본 소스를 별도 레이어로 배치한다. 현재 업로드 준비의 결정론적 리사이즈·재인코딩과 생성형 재생성을 구분했다.

패널 스킬은 설치·실행하지 않았다. 원문 이미지 생성 프롬프트나 샘플 비트맵을 앱에 복사하지 않았다. 이미지 입력·저장·렌더·출력 경로를 읽은 독립 검토에서 생성형 이미지 API 호출을 발견하지 않았다.

독립 검토가 찾은 별칭 이름의 직접 lookup 오류를 resolver와 런타임 테스트로 수정한 뒤 최종 검사·빌드를 실행했다. 초기 빌드·브라우저 검수의 Windows 샌드박스 경로/로컬 네트워크 접근 오류는 같은 명령의 권한 검토 후 재실행으로 해결했다.

후속 검토에서 홈 선택 체크가 12px/모바일 11.2px 슬롯보다 크게 표시되고 업로드 성공 체크가 기존 28px 위계보다 작아진 것을 확인했다. 홈 SVG는 슬롯 너비를 따르고 성공 SVG는 기존 `1.75rem` 크기를 사용하도록 CSS를 수정한 뒤 해당 표시 크기를 추가 검수했다.

검수는 별도 origin과 새 브라우저 컨텍스트, 기존 예시 데이터로 진행했다. 현재 사용자 초안은 사용하지 않았다. 화면 캡처·결과 JSON은 로컬 `tmp/xxd-ui-qa/`, 실제 파일과 결과 JSON은 `tmp/xxd-export-qa/`에 있다. 대표 모바일 홈·스타일·출력, 데스크톱 편집·사진 시작과 실제 PNG를 열어 시각 검수했다. 모든 비율·배율의 출력 매트릭스나 역사 아카이브 검사를 이번 아이콘 변경에서 실행했다고 주장하지 않는다.

사용자에게 제공된 portable brain의 `protocols/permissions.md`, memory 파일과 `.agent/tools/memory_reflect.py`는 이 체크아웃에 없었다. 해당 CLI를 실행하거나 메모리를 갱신했다고 기록하지 않으며 이 문서가 이번 변경·검증 기록이다.
