# 설치된 Stone 테마의 엄격한 준수 · 2026-10-10

사용자 지시: “설치한 테마를 엄격하게 준수하라고”.

## 기준

`src/app/shadcn-theme.css`의 CLI 생성 원본을 앱 색상과 radius의 유일한 기준으로 삼는다. 원본 파일은 수정하지 않는다. `--only theme` 요청이므로 기존 서체·레이아웃·실제 기능은 유지한다. 홈의 특색은 이 색상 체계 안에서 조판과 작품 진열로 표현한다.

최초 적용에서 별도로 혼합했던 보조 텍스트·입력 경계와 녹색 성공 팔레트를 제거한다. 의미 별칭은 공식 변수에 직접 연결한다.

| 앱 의미 | 공식 토큰 |
| --- | --- |
| 배경 | background |
| 표면·헤더·입력 | card |
| 오버레이 패널 | popover |
| 작업대·상태 표면 | muted |
| 주 텍스트·성공 상태 | foreground |
| 보조 텍스트 | muted-foreground |
| 주 행동 / 글자 | primary / primary-foreground |
| hover·선택 표면 | accent |
| 구획선 / 입력 경계 | border / input |
| 포커스 | ring |
| 오류 | destructive |

앱의 비활성·hover·선택 표면과 선을 별도 혼합색으로 만들지 않는다. 컨트롤·패널의 모서리는 생성된 `radius-sm/md/lg` 등 스케일을 사용한다. 원형 thumb·스피너·상태 기호, 카드 작품의 고유 기하와 인쇄 스타일은 별도의 기능 의미를 유지한다. 테마에 없는 shadow·backdrop는 중립 검정 alpha로 처리한다.

공통 카드 렌더러·XIVAPI 아이콘 원본·카드 팔레트·내보내기는 앱 테마를 상속하지 않는다. 앱의 의미 별칭을 교정하는 작업이며 카드 테마를 Stone으로 변경하는 작업이 아니다.

## 검증

최종 실행 결과와 런타임 증거는 `tmp/identity-2026-10-10/`에 남긴다. 기존 portable-brain 경로가 저장소에 없어 이 문서를 변경·검증 기록으로 사용한다.

- 생성된 프리셋 SHA-256은 `E25912D9A98152C90EC17352DBE22A6573928522063C807DDD3CCDA906C55F92`로 유지됐다.
- 보정 전 원본 토큰과 달랐던 앱 별칭 7개를 확인했다. 보정 후 20개 색상 별칭이 42개 홈 조건과 24개 나머지 경로 조건에서 원본과 일치했다. 화면 폭은 실제 DOM viewport 값으로 기록했다.
- 홈·보관함·헤더·사진 시작·스타일·편집기·출력의 활성 UI 상태색과 반경을 보정했다. 과거 CSS의 무효화된 선언은 새 활성 규칙으로 덮이며 카드·직업 팔레트·인쇄 스타일을 바꾸지 않는다.
- 마지막 독립 검토에서 스피너의 혼합색을 border 토큰으로, 모바일 출력 및 출력 미리보기의 따뜻한 그림자 색을 중립 검정 alpha로 수정했다. 이후 최종 프로덕션 빌드 통과.
- TypeScript·ESLint 통과. 전체 테스트 248개 통과, 실패 0개, 기존 아카이브 검사 29개 skip. 카드 테마 변수 격리 검사도 포함한다.
- 원본 색상 쌍의 정적 계산에서 primary/primary-foreground는 light 16.76:1, dark 13.92:1이다. muted-foreground/background는 light 4.81:1, dark 7.63:1이다. 모든 요소·상태의 화면 대비를 계산한 결과로 확대 해석하지 않는다. 밝은 muted 저장 표면 위 레이블 및 선택 스타일 인덱스는 foreground 역할을 사용한다.
