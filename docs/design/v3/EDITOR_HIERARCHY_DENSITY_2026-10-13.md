# 편집기 위계·선택·수치 조절 정리

2026-10-13 후속 요청의 현재 구현 기록. 이전 탐색 수정 이후 사용자가 도구 레일 유지, 모바일 더보기의 같은 시트 전환, 선택 효과·여백 통일, 참고 사이트의 UI 서체와 사용법 안내를 요청했다. 현재 앱 계약은 루트 DESIGN.md §5.1이다.

## 적용

- 데스크톱에서 상세 항목을 접어도 사진·문구·디자인 48px 레일을 유지한다. 240px 목록만 숨기며, 넓은 화면의 우측 중복 도구 탭은 제거했다. 태블릿에서는 우측 탭으로 전환한다.
- 모바일 네 도구는 같은 370×405px 속성 시트를 공유한다(390×844 기준). 더보기도 속성 본문의 내용을 교체하며 별도 팝오버를 쌓지 않는다. 한 번에 한 도구만 선택 상태다. 짧은 화면·키보드 입력에서는 시트를 확장하고 도크를 숨긴다.
- 선택은 네비게이션과 같은 연한 파란 배경·파란 글자·8px 모서리다. 굵은 왼쪽 선과 inset 선택 그림자를 제거했다. 포커스 outline과 효과 switch의 켜짐 위치는 각 기능의 의미로 유지한다.
- 사진·서체·효과·화면 확대에 공통 숫자 컨트롤을 적용한다. 슬라이더와 숫자 입력은 같은 줄, 실제 조작 높이 44px, 숫자 칸 96px다. 입력 중간 상태·IME 조합을 유지하며 유효값을 즉시 반영하고 완료 시 범위를 적용한다. 백분율 슬라이더의 DOM 범위도 표시 단위와 맞췄다.
- 문구 편집은 레이블과 입력 사이 8px, 설정 그룹 사이 16px를 기준으로 정리했다. 중첩 구분선을 제거하고 세부 설정·초기화 주변 여백을 맞췄다.
- [원페이지 포스터 메이커](https://doldimseom.github.io/doldimseumsheet/DimseomOnepagePosterMaker.html)의 실제 화면을 브라우저로 확인했다. UI 서체는 로컬 Noto Sans KR Variable, 일본어는 Noto Sans JP Variable로 적용한다. 카드 작품의 서체는 유지한다.
- 수동 4단계 사용법 안내를 추가했다. 데스크톱 헤더와 모바일 더보기에서 열며, 작업 도구·문구 선택·사진/글꼴 조절·이미지 저장을 설명한다. KO/EN/JA, Escape, Tab 순환과 호출 버튼 포커스 복귀를 제공한다.

## 검증 범위

- 전체 테스트 406개: 377개 통과, 기존 이력 검증 29개 보류, 실패 0개. TypeScript·ESLint·프로덕션 빌드 통과.
- 1440×900 데스크톱 접힘에서 레일 48px과 세 도구를 유지하고 상세 목록만 0px으로 숨기는 것을 확인했다. 1024px 전환에서 캔버스 x=0이며 포커스가 태블릿 도구 탭으로 복귀한다.
- 390×844에서 네 도구 모두 같은 위치·너비·높이의 패널 한 개만 열리고 선택도 한 개다. 320×390과 844×390에서 가로 넘침이 없으며 입력 공간을 우선한다.
- 네비게이션과 문구 행의 실제 computed style이 동일하다: 배경 `rgb(229,244,255)`, 글자 `rgb(7,91,150)`, 경계 transparent, 그림자 none, 반경 8px.
- 공통 수치 입력에서 `9` 중간값과 IME 조합 중 값은 미반영, 완성된 `90`은 반영됨을 확인했다. 슬라이더와 숫자 입력의 y 좌표와 높이 44px가 같고, 실행 취소는 100, 다시 실행은 90으로 복귀했다.
- 사용법의 네 단계, 완료·Escape·호출 버튼 포커스 복귀를 확인했다. 320×390 안내는 화면 내부에 위치하며 더보기 시트와 함께 쌓이지 않는다. 화면 확대 입력에 포커스가 유지된다.
- KO/JA/EN UI 서체와 Noto 등록을 확인했다. 별도 영어 브라우저 컨텍스트에서도 Noto Sans KR의 로컬 face가 등록·로드된다. UI의 Noto 적용 후에도 카드 루트의 기존 DM Sans 스택과 이름의 Cormorant Garamond는 유지된다.
- 키보드 검증은 브라우저의 입력·IME 이벤트와 축소된 viewport 조건이다. 실제 휴대전화 소프트 키보드 테스트로 표현하지 않는다.
