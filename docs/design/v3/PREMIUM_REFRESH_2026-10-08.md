# 편집 스튜디오·카드 현지화·원본 직업 아이콘 · 2026-10-08

사용자 요청: 모바일과 데스크톱의 시각 품질 향상, 한국어 카드의 서버/레벨/내용 현지화, 모험가 기록 깃발을 카드 최상단 및 테두리 위에 배치, 임의 마스크 직업 아이콘을 모두 삭제하고 XIVAPI 고화질 원본만 사용.

## 구현

- 편집기: 84px 작업 도크, 입체감 있는 카드 스테이지, 묶인 툴바, 독립된 인스펙터와 44px 이상 조작부. 모바일은 36svh 스테이지, 헤더 아래에 고정되는 분할 탭, 자연스럽게 이어지는 패널.
- 헤더: 문서 이름과 저장 상태의 위계, 언어 선택, 단일 이미지 저장 행동. 홈/갤러리/사진 시작/저장 화면에도 일관된 표면과 컨트롤 적용.
- 기존 모바일 inspector의 top:-56px 및 z-index:80이 탭을 덮던 문제 제거. 비기능성 드래그 핸들 제거. 사진 조절 제목과 초기화 버튼은 한 줄로 정렬.
- 카드: `card-copy.ts`를 고정 문구의 단일 레지스트리로 사용. 한국어 서버, 데이터센터, 언어, 서비스/지역, 장식 문구를 현지화. 마스터와 b/c 레이아웃, 사진 대체 설명 및 캔버스 설명 모두 같은 현지화 경로 적용.
- 레벨 숫자는 원래 값 그대로 유지하고 한국어 레이블과 함께 표시. 알 수 없는 고유명/사용자가 작성한 원문은 추측 번역하지 않음. 기본 샘플 소개는 정확한 기본 문자열과 내장 사진이 일치할 때만 표시 언어에 맞춰 렌더링.
- 한국어와 일본어 인쇄 문구에 등록된 CJK 서체 및 단어 단위 줄바꿈 적용. 글꼴 준비 요청에 고정 문구와 현지화된 샘플 소개도 포함.
- 기록 깃발: top0, z-index11. 인쇄 프레임 z-index10. 16:9에서 아래로 이동하던 값 제거.
- 직업 아이콘: 생성된 마스크/SDF 복사본 138개와 별도 후보 176개, 총314개 파일 삭제. 원본 XIVAPI SVG/256px PNG 및 출처/무결성 검증은 보존. 현재 resolver는 XIVAPI 경로만 허용하고 과거 마스크 fallback이 없음.
- 기존 76px 파생 마스크 기준의 직업 문양 크기 제한을 256px 원본 해상도에 맞게 변경. 각 카드/비율의 문양 공간을 별도 상한으로 적용해 4×에서도 원본 PNG 해상도를 넘지 않도록 유지.

## 검증

- 최종 npm test: 264/264 통과. npm run lint: 오류/경고 없음. npm run build: 타입 검사 포함 통과.
- 프로덕션 정적 빌드에서 카드 3종의 한국어 문구를 직접 확인: 서버 모그리, 데이터센터 카오스, 레벨100, 서비스 글로벌/유럽, 언어 한국어/영어 및 번역된 장식 문구.
- 기록 깃발 1:1/4:5/3:4/9:16/16:9 전부 실제 DOM 좌표에서 카드 상단과의 차이0px, 깃발 z11/프레임 z10.
- 기록 카드 604px 프리뷰의 직업 문양: 이전 10.9px → 최종36.16px. 선택 출처 `xivapi-svg`; 원본 Red Mage SVG 사용.
- 편집기 KO/EN/JA × 320/390/768/1440px: document scrollWidth == clientWidth. 모바일 탭과 인스펙터 겹침 및 헤더 아래 sticky 위치 확인.
- 기존 사용자 초안은 localhost:3000에서 읽기 검수만 진행. 샘플/비율/언어 변경은 별도 origin 127.0.0.1:4324에서 수행.
- React 실제 렌더 테스트가 사용자 지정 소개/부대명을 보존하고 마스터/b/c 현지화와 글꼴 요청을 검증. 아이콘 체크는 원본 SHA와 크기/사용처 및 생성 자산 부재를 검사.
- 이번 최종 카드 변경 후 전체 export 비율/포맷 실파일 매트릭스는 새로 수행하지 않았다. 기존 내보내기 회귀 테스트와 글꼴 준비/원본 해상도 상한 검증을 구분한다.
